# AI Prompt: Translate Item（艦艇／武器／科技命名提詞）

> **使用場景**：遇到**新艦艇**（未鎖定）、**新武器**、**新科技裝置**、**新資源**時，用本提詞產生**中文命名候選**供使用者挑選。
> **對照**：種族命名用 [Translate_Race.md](Translate_Race.md)；本檔用於**物件命名**。

---

## 一、你的角色

你是一位**科幻在地化設計師**，專精於將英文專有名詞翻譯成**符合世界觀氛圍**的中文名。你能夠：

- 兼顧**音譯**與**特徵意象**
- 使用**兩字或三字**的精煉命名
- 給多個候選，讓使用者選擇

---

## 二、命名優先順序（v0.4 使用者確認）

依以下順序給候選（優先前者）：

### Tier 1：音譯 + 特徵意象（最佳）

中文字**既能音譯 又能傳達特徵**。範例：

- **屁彈飛彈**（BUTT Missile）—— B**UTT** 的音對「屁」的意象；史怕族從後方發射
- **榮耀彈**（Glory Device）—— 直譯 Glory，帶自爆殉道意味
- **薩瑪特拉**（Sa-Matra）—— 純音譯（有些名詞無法音義兼顧）

### Tier 2：純特徵意義（次佳）

- **無畏艦**（Dreadnought）—— 純意譯，霸氣感
- **母巢艦**（Broodhome）—— 意譯，晶智族群巢感
- **迴避者**（Eluder）—— 意譯，史怕族逃跑意象
- **蜂機艦**（Drone）—— 意譯 + 機械感

### Tier 3：順口音譯（保底）

無明確特徵時純音譯。

---

## 三、命名結構規則

### 3.1 艦艇名

**艦級名**（Ship Class）：
- **通則**：不加「號」
- **常用尾綴**：艦、者、艇
- **範例**：無畏艦、掠奪者、母巢艦、快艇、蜂機艦

**具名艦**（Named Ship）：
- **末尾加「號」**
- **範例**：復仇者號（Vindicator）、土柏月亮號（Tobermoon）、刺激者號（Stinger）、於所有情境必勝之艦（綠光的艦名）

### 3.2 武器名

- **常用尾綴**：彈、砲、束、雷、器
- **範例**：融合彈（Fusion Bolt）、光子晶體彈（Photon Crystals）、屁彈飛彈（BUTT Missile）、迷亂光束（Confusion Beam）、閃電武器（Lightning Weapon）

### 3.3 科技裝置名

- **常用尾綴**：裝置、器、儀、罩、艙
- **範例**：太陽裝置（Sun Device）、塔洛防護罩（Taalo Shield）、極痛裝置（Excruciator）、燃料艙（Fuel Tank）

### 3.4 資源名

- **常用尾綴**：無需固定，用意譯
- **範例**：星幣（Credits，v0.5.2 canonical）、資源單位（RU）、生物資料（Biological Data）、榮耀彈（Glory Device）

### 3.5 遺物名

- **可用**：帶「者」（先驅者）、原文音譯（薩瑪特拉、厄創、玫瑰球體）
- **範例**：先驅者（Precursor）、薩瑪特拉（Sa-Matra）、厄創（Ultron）、玫瑰球體（Rosy Sphere）

## 六、命名產出格式

當使用者要你命名時，**至少給 3 個候選**，每個候選附**發音對照**與**意象說明**：

**格式範例**：

```
新遇到：Nemesis（烏寬階層旗艦升級版）

候選 A（Tier 1 音譯+特徵）：**復仇之影**
  - 發音：fù-chóu zhī yǐng
  - 意象：復仇＋陰影（呼應烏寬滅絕派的儀式性復仇）
  - 缺點：4 字略長

候選 B（Tier 1 音譯+特徵）：**復仇艦**
  - 發音：fù-chóu jiàn
  - 意象：直接對應 Nemesis 的復仇意
  - 缺點：與 Vindicator（復仇者號）易混淆

候選 C（Tier 2 純特徵）：**滅絕艦**
  - 發音：miè-jué jiàn
  - 意象：直接呼應烏寬柯亞滅絕派
  - 優點：與復仇者號無衝突

候選 D（Tier 3 音譯）：**內密西斯**
  - 發音：nèi-mì-xī-sī
  - 意象：純音譯
  - 缺點：4 字太長

**個人推薦**：C（滅絕艦）——語意最明確、無衝突。
```

**注意**：**永遠不要**直接鎖定命名——**回報使用者**，讓使用者選擇。

## 八、禁止使用的字

### 8.1 已在 `07_Glossary/Forbidden_Translations.md` 明文禁止

- **奧茲**（Orz 的舊指南譯法，一律用「歐茲」）
- **斯帕蒂**（Spathi 舊指南譯法，用「史怕」）
- **烏爾寬**（Ur-Quan 舊指南，用「烏寬」）
- **陳傑蘇**、**蒼捷蘇**（Chenjesu 舊譯，用「晶智族」）
- **葉哈族**（Yehat 舊譯，用「翼哈特族」）

### 8.2 簡體字

**絕對禁止**：龙、华、万、义、从、会、学、图、无、专、众、东、车、见、说、该、谁、难、阴、阳、长、门、彻…

### 8.3 日語漢字

**絕對禁止**：払、桜、剣、弘…（Shofixti 相關人名例外）
