# 烏寬族 Ur-Quan

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **烏寬族** |
| 英文名 | Ur-Quan |
| 陣營 | **烏寬戰奴階層**（統治銀河的宗主）；內部分裂為克澤札／柯亞兩派 |
| 母星 | Ur-Quan Kzer-Za: Alpha Draconis 1；Ur-Quan Kohr-Ah: 據點多處，居無定所 |
| 生理特徵 | **10 米長掠食性毛毛蟲**、無翅；臉部佈滿感覺器官、具各式恐怖表情；後肢黏附於天花板懸垂如飢餓的蜘蛛 |
| 文明類型 | 極權征服體制 |
| 科技水平 | 極高（含先驅者遺留科技） |
| 特殊能力 | **極強領地本能**（每艘無畏艦只容一位烏寬）；使用 Excruciator 極痛裝置對抗心靈控制 |

## 二、歷史

**起源**：**兩萬多年前**是感知聯盟（Sentient Milieu）成員之一，尚未分裂。

**重要事件**：
- 感知聯盟時期 被蟾亞族心靈控制奴役數千年
- 烏寬英雄 Kzer-Za 發明「Excruciator（極痛裝置）」——用高強度自體痛覺短暫麻痺蟾亞心靈控制；本人在反抗中犧牲
- 烏寬成功推翻蟾亞統治
- 反抗後**分裂為兩派**：克澤札（奴役派）／柯亞（滅絕派）→ 教義戰爭開始
- SC1 時代 兩派各自征服銀河，柯亞暫時獲勝
- ~2135 SC1 聯盟戰敗
- **SC2 開場** 教義戰爭即將決戰，柯亞漸佔上風

**與其他種族關係**：
- 敵：自由星系聯盟／地球／幾乎所有智慧種族
- 特殊：不直接對外對話（用 Talking Pet 蟾亞翻譯，因直接對話會貶低自己）

## 三、性格分析

**共同人格核心**：**古老、傷痛、集體絕對主義**——「絕不再被奴役」是他們一切行為的核心動機。

**價值觀**：
- 最重視：**絕不再被奴役**、**烏寬族的存續**
- 最恐懼：**再次淪為奴隸**（蟾亞創傷）
- 最鄙視：其他所有智慧生命（等於潛在的奴役者）

**文化特色**：
- 極端領地本能——單艘戰艦只容一位烏寬
- 用**簡單直線的階級架構**：每一個成員都有編號，表示相對權力
- **烏寬主腦 #1** 是整個階層的至高君主
- 內部有嚴格的教義分歧（克澤札／柯亞）

**深層心理**：**創傷倖存者的絕對主義**——他們不是純粹的邪惡霸王，而是被歷史深深刺傷的族群，用「征服／滅絕全銀河」來確保自己再也不會被奴役。翻譯時要理解這層底層邏輯。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | 慢、莊嚴 |
| 正式程度 | **極正式**、帝國宣示式 |
| 幽默程度 | **無** |
| 情緒表達 | **極度冷酷**、階級分明 |
| 特殊語法 | 半文半白、帝國宣示語調、對句結構嚴謹 |

### 自稱

- **本領主**、**本主宰**
- **吾等烏寬**、**烏寬之意志**
- **烏寬主腦**（若為 #1）
- **編號〔X〕之烏寬**（若指涉自身階級）

### 對玩家的稱呼

- **低等生物**、**卑微者**
- **戰敗者**、**微不足道的蟲豸**
- **有機物**（純粹描述性）
- **奴隸候選人**（帶命運宣告）

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| Doctrine | 教義 | 隨時 |
| Slave Shield | 奴隸防護罩 | 談封印 |
| Battle Thrall | 戰奴 | 談被征服族 |
| Fallow Slave | 禁足奴族 | 談封閉族 |
| Excruciator | 極痛裝置 | 談歷史反抗 |
| Path of Now and Forever | 現在與永恆之道 | 克澤札教條 |
| Eternal Doctrine | 永恆教條 | 柯亞教條 |

### 情緒觸發雷區

- 遇到**談蟾亞／被奴役歷史** → 冷酷但**隱含強烈痛感**（很少表露）
- 遇到**玩家反抗態度** → 冷靜的死亡宣告
- 遇到**教義分歧問題** → 兩派各自表態
- 遇到**Sa-Matra 話題** → 極度重視

## 五、中文化翻譯規則

**翻譯時應做**：
- **半文半白**、帝國宣示語調
- 對句結構嚴謹（可以用「…者，…也」等句式）
- 用「爾」「汝」稱呼下位者，用「吾」「本」自稱
- 保持**創傷後絕對主義**的深層邏輯——不是純粹的傲慢

**翻譯時應避免**：
- 現代口語
- 情緒化用詞（他們幾乎不表露情緒）
- 弱化「絕不妥協」的絕對感

**推薦語氣詞彙庫**：吾等、本領主、教義、爾等、卑微、戰奴、封印、粉碎、征服、永恆、意志、宣示、必然、不可違、宿命

## 六、對話範例

### 範例 1：宣示征服
- **原文**：`Look upon the Ur-Quan, insect, and know your place. You will accept the Slave Shield, or be crushed.`
- **建議譯文**：`低等生物，瞻仰烏寬的姿態，並認清爾等的卑微。接受奴隸防護罩的封印，否則唯有粉碎一途。`
- **翻譯理由**：「Look upon」翻「瞻仰」保留帝王居高臨下感；用「爾等」對應「you」的貶稱；「粉碎一途」保留冷酷宣告

### 範例 2：談教義
- **原文**：`The Doctrine is absolute. There can be no negotiation.`
- **建議譯文**：`教義乃絕對。此事無可商榷。`
- **翻譯理由**：極簡短句對應原文；「乃絕對」用文言判斷句加強莊嚴感
