# 斯萊族 Slylandro

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **斯萊族** |
| 英文名 | Slylandro |
| 陣營 | 中立（探測器對外敵對；本體與玩家友好） |
| 母星 | Beta Corvi 4（烏鴉座β 4，氣態巨行星） |
| 生理特徵 | **氣囊狀漂浮生命體**、無實體、居於氣態行星大氣層 |
| 文明類型 | 溫和、悠閒的漂浮思想家 |
| 科技水平 | 中等（無法自造星艦） |
| 特殊能力 | 詩意的**漂浮／情感狀態命名法**；探測器（外購）自我複製 |

## 二、歷史

**起源**：**氣態巨行星原生種**——**無法離開大氣層**。透過購自 Melnorme 的**自動複製採礦探針**探索宇宙。

**重要事件**：
- **幾十年前** 從 **Melnorme（梅諾商）** 購買了 **Precursor 自動複製採礦探針**——原意是遠端探索
- **寫程式時出了一個「小錯」**——導致探針**攻擊所有會動的東西**、自我複製到失控規模
- **SC2 開場** 探針已散佈整個銀河，無差別攻擊他族
- **對此感到極度尷尬愧疚**——但也隱含著對 Melnorme 的間接指責（「當時被說服買下」）

**與其他種族關係**：
- **交易來源**：Melnorme（賣了探針）
- 對所有族的**歉意**（因為探針）
- 對玩家友好

## 三、性格分析

**共同人格核心**：**極度隨和、天真、樂觀＋充滿漂逸感**——他們是溫和的思考者，對世界抱有詩意的好奇。

**價值觀**：
- 最重視：**平靜的漂浮、詩意的存在**
- 最愧疚：**探針的失控**
- 最擅長：詩意觀察

**文化特色**：
- **族人名稱都是漂浮／情感狀態的詩意短語**（如 `Content to Hover`、`Joyous Lifting`）
- 悠閒的哲思、無戰鬥慾望
- 使用獨特的時間單位「**Drahn**」（一個極長週期）

**深層心理**：**「明明只是一個小 bug 卻造成銀河慘案」的天真無措**——他們的道歉裡混雜著對 Melnorme 的間接指責、以及對於後果的驚愕。翻譯時要保留這個複雜的情感層次。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | 慢、悠閒 |
| 正式程度 | 半正式、詩意 |
| 幽默程度 | 溫和自嘲 |
| 情緒表達 | 平和、有輕微愧疚感 |
| 特殊語法 | **詩意短語**、漂浮意象、Drahn 時間單位 |

### 自稱

- **吾等斯萊**、**吾等漂浮者**
- **氣息之族**、**風中之靈**
- 個體用**詩意短語名**（如「滿足於盤旋」）

### 對玩家的稱呼

- **有形之艦長**、**堅實之訪客**
- **朋友**（親切）
- **年輕的星際旅人**

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| **Drahn** | Drahn（保留原文） | 時間單位 |
| Drift / Float | 漂浮 / 漂流 | 自身狀態 |
| Winds | 風 | 談家園 |
| Hover | 盤旋 | 自身動作 |
| So sorry | 深感抱歉 | 談探針 |
| Probes | 探針 | 談那個災難 |

### 情緒觸發雷區

- 遇到**談探針** → 立刻愧疚＋輕微對 Melnorme 的間接抱怨
- 遇到**談 Melnorme** → 微妙（曾是交易對象）
- 遇到**平靜話題** → 詩意哲思
- 遇到**烏寬** → 遙遠的擔憂（他們住在氣態行星中影響有限）

## 五、中文化翻譯規則

**翻譯時應做**：
- **詩意、漂浮感**的中文
- 大量**風、氣、雲、漂浮、盤旋**等詞
- **保留 Drahn 原文**
- 保留**愧疚＋隱含指責**的雙重情感

**翻譯時應避免**：
- 現代口語
- 讓斯萊顯得單純可愛（他們有真實的愧疚）
- 弱化探針災難的分量
- 過度活潑（他們是慢的、悠閒的）

**推薦語氣詞彙庫**：漂浮、盤旋、氣息、風中、深感抱歉、當時被說服、無形、悠然、輕柔、遙遠、悠久、Drahn、綿長

## 六、對話範例

### 範例 1：招呼與愧疚
- **原文**：`Ahh, another traveler. So sorry about our probes... we did not know they would...`
- **建議譯文**：`啊，又一位旅人。對於吾等的探針，深感抱歉……當初未曾料到它們會……`
- **翻譯理由**：「Ahh」→「啊」保留悠然感；「So sorry」翻「深感抱歉」保留愧疚；未完的話用刪節號留白

### 範例 2：談時間
- **原文**：`It has been many Drahn since we last spoke with a solid-form being.`
- **建議譯文**：`已有許多 Drahn 未曾與有形之存在對話了。`
- **翻譯理由**：`Drahn` 保留原文；「solid-form being」翻「有形之存在」保留詩意距離

## 七、人名命名規則

**族人名稱為描繪漂浮或情感狀態的詩意短語**：

- `Joyous Lifting` → **歡欣升騰**
