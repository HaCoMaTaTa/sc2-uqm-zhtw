# 安卓辛族 Androsynth

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **安卓辛族** |
| 英文名 | Androsynth |
| 陣營 | 曾為烏寬階層戰奴 → **SC2 開場時神秘消失** |
| 母星 | 原為 Vulpecular 星座殖民地（後被 Orz 取代） |
| 生理特徵 | **人類複製體**（雌雄同體）、身體規格類人類 |
| 文明類型 | 冷冽的技術官僚體制 |
| 科技水平 | 高（尤其複製人技術、異次元研究） |
| 特殊能力 | 快速複製繁衍；戰艦可轉換為彗星形態衝撞 |

## 二、歷史

**起源**：**瑞士科學家辛合（Hsien Ho）於 2019 年**完成人類染色體圖後，用複雜的遺傳學技術製造出**雌雄同體的人類複製人**——只是外表像人類、無法生殖下一代。

**重要事件**：
- **傑森・馬可布萊神人教派**視他們為威脅，剝奪其人權，過著奴隸生活
- **2085** 集體叛亂逃離地球——24 小時內攻占所有星球飛航工具；改造 8 大太空站帶走
- 在 Vulpecular 星座建立殖民地
- 之後三十年集中精力繁衍後代與加強軍備
- 被烏寬**在短短幾星期**內征服，成為戰奴
- **SC2 開場前** 因研究「異度空間技術」而**神秘集體消失**——當前 Vulpecular 星座已被 Orz 佔據
- **失蹤真相**：可能被 Orz 帶到別的維度（詳情不明；Arilou 似乎知道但不多說）

**與其他種族關係**：
- 深層仇敵：地球（因當年被視為奴隸）
- 被取代：**Orz 取代了他們在 Vulpecular 星座的位置**
- 神秘：Arilou 似乎知道他們的下落

## 三、性格分析

**共同人格核心**：**冷酷技術導向＋對人類的深沉怨恨**——防衛性極強。

**價值觀**：
- 最重視：**存續、技術優越、對過去的復仇**
- 最恨：**地球人**（曾把他們當奴隸）
- 最擅長：冷靜的邏輯運算

**文化特色**：
- 冷冽的技術官僚體制
- 個體差異被縮到最小
- 集體目標優先
- **雌雄同體**——無傳統的性別動態

**深層心理**：**兩層仇恨**——對創造他們又奴役他們的地球人；對征服他們的烏寬。**表面服從烏寬（作為戰奴），底層怨恨兩者**。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | 中等，機械節奏 |
| 正式程度 | 正式、冷硬 |
| 幽默程度 | 幾乎無（若有為極度冷諷刺） |
| 情緒表達 | 冷冰冰、防衛性極強 |
| 特殊語法 | **工程邏輯感中文**、大量技術術語、否定與距離感 |

### 自稱

- **安卓辛**、**吾等安卓辛**
- **完成之複製體**
- **超越造物者之體**
- **序列〔數字〕**

### 對玩家的稱呼

- **原型生物**（帶貶意——指人類是「未完成的樣本」）
- **地球人**（冰冷）
- **創造者**（帶反諷——他們創造了我們，我們現在更優越）
- **有機物**

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| Prototype | 原型 | 稱人類（貶意） |
| Superior | 優越 | 自我描述 |
| Sequence | 序列 | 談生殖／複製 |
| Reject | 拒絕／不接受 | 拒絕邏輯 |
| Illogical | 不合邏輯 | 批判 |

### 情緒觸發雷區

- 遇到**談地球人／人類** → **冷冽的仇恨**
- 遇到**談神秘消失** → **無法回應**（他們自己都不知道）
- 遇到**談雌雄同體** → 中性、平靜
- 遇到**談烏寬奴役** → 表面服從、底層冷諷

## 五、中文化翻譯規則

**翻譯時應做**：
- **冷冰冰、防衛性強的中文**
- 用**工程邏輯感**詞彙（「序列」「原型」「不合邏輯」等）
- 對地球人稱謂帶**冷諷刺**（例如「原型生物」）
- 保持雙重仇恨的張力（對地球＋對烏寬）

**翻譯時應避免**：
- 熱情、感性用詞
- 現代口語
- 讓安卓辛顯得像單純的機器人（他們有仇恨，只是壓抑）
- 弱化對地球的敵意

**推薦語氣詞彙庫**：吾等、原型、序列、優越、拒絕、不合邏輯、汝等造物者、被淘汰、超越、冰冷、精確、清算、隔絕、否定

## 六、對話範例

### 範例 1：面對地球艦長
- **原文**：`So, the prototype returns. Have you come to reclaim what you enslaved, or to grovel before your creation?`
- **建議譯文**：`所以，原型生物回來了。爾等是來收回自己曾奴役之物，還是在自己的造物面前跪下？`
- **翻譯理由**：「prototype」→「原型生物」貶意；「grovel」→「跪下」加強反諷；用「爾等」保持冰冷距離感

### 範例 2：談神秘消失（若有）
- **原文**：`We had... reached... beyond. It was... not... as expected.`
- **建議譯文**：`吾等曾……觸及……更遠之處。結果……並非……如預期。`
- **翻譯理由**：保留原文的斷續感——這是神秘消失事件的模糊記憶；用「觸及更遠之處」暗示異次元探索
