# 先驅者 Precursor

> **性質**：25 萬年前的高等種族，**已消失無蹤**。無對話，只在遊戲中以**遺物**與**歷史提及**形式出現。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **先驅者** |
| 英文名 | Precursor / Precursors |
| 陣營 | 遠古（已消失） |
| 母星 | 不明 |
| 生理特徵 | **巨大體型**（不像兩足動物）；船艦操縱桿極大，需三人扳一個開關；椅子床適合上古長毛巨象 |
| 文明類型 | 極高等超前文明 |
| 科技水平 | **極高**（銀河所有現存種族之上） |
| 特殊能力 | 遺留了 Vindicator、Sa-Matra、Ultron、Taalo Shield、Sun Device 等所有 SC2 高階神器 |

## 二、歷史概要

- 約 25 萬年前的**銀河系鼎盛期文明**
- 遺物散佈於銀河各處，SC2 主線劇情大量圍繞這些遺物
- **神秘消失**——原因不明
- 盟友：**塔洛族**（矽基和平種族；製作了 Taalo Shield）

## 三、對翻譯的意義

- **遊戲中無 Precursor 對話**——他們早已消失
- 名字會出現在**遊戲敘事、其他族的對白裡**（例如「這是先驅者的遺物」）
- **一律用「先驅者」譯名**——不接受其他變體（如「先驅」「先民」「祖先」等）

## 四、相關遺物（見 `05_Technology/Artifact.md`）

- **Vindicator（復仇者號）**——玩家旗艦
- **Sa-Matra（薩瑪特拉）**——烏寬終極戰爭平台
- **Ultron（厄創）**——憂特族的神祕裝置
- **Taalo Shield**——傳說中的心靈防護裝置
- **Sun Device（太陽裝置）**——用於加速 Chmmr 融合
- **Rosy Sphere（玫瑰球體）**——Ultron 組件
