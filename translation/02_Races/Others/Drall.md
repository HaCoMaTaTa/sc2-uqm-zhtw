# 卓爾族 Drall

> **性質**：感知聯盟創始四族之一；被 Dnyarri 命令其他被奴役族群圍攻消滅。無對話，只在 lore 中提及。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **卓爾族** |
| 英文名 | Drall |
| 陣營 | 感知聯盟時代（已滅絕） |
| 母星 | 不明（感知聯盟區域） |
| 生理特徵 | **高瘦人形**（達 3 米高）；演化自類 mud-skipper（mud-skipper 是「彈塗魚」——嘴／肺＋鰓） |
| 文明類型 | 感知聯盟創始成員 |
| 科技水平 | 未知（文化幾乎全無記錄） |
| 特殊能力 | 未知 |

## 二、歷史概要

- **感知聯盟創始四族之一**
- 文化幾乎全無記錄留下
- **Dnyarri 統治時期被判定「劣等」**——**Dnyarri 命令烏寬與 Mael-Num 消滅他們**
- 整族滅絕

## 三、對翻譯的意義

- **遊戲中無 Drall 對話**
- 名字可能在**談感知聯盟史**時出現
- **一律用「卓爾族」譯名**
