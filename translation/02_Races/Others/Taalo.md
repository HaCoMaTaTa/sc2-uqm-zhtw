# 塔洛族 Taalo

> **性質**：先驅者盟友；感知聯盟時代**唯一能抗拒 Dnyarri 心靈控制的族群**；被 Dnyarri 命令其他被奴役族群圍攻消滅。無對話，只在 lore 中提及。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **塔洛族** |
| 英文名 | Taalo |
| 陣營 | 感知聯盟時代（已滅絕） |
| 母星 | Delta Vulpeculae 2c（狐狸座δ 2c） |
| 生理特徵 | **矽基和平種族**、非碳基 |
| 文明類型 | 和平哲學文明 |
| 科技水平 | 極高（與先驅者為盟友） |
| 特殊能力 | **對 Dnyarri 心靈控制免疫**（獨有） |

## 二、歷史概要

- **感知聯盟時代的核心成員**
- **感知聯盟中唯一免疫 Dnyarri 心靈控制**——因此成為 Dnyarri 的頭號威脅
- **Dnyarri 命令所有其他被奴役族群圍攻塔洛母星**、將其滅絕
- **滅絕前疑似接近完成**一個「能將心靈防護力擴散給其他族群的裝置」——即遊戲中玩家可找到的 **Taalo Shield** 相關線索
- 是**先驅者的盟友**

## 三、對翻譯的意義

- **遊戲中無 Taalo 對話**
- 名字在**其他族的敍事對白裡出現**（例如烏寬談到 Excruciator 反抗事件；晶智族談到古代哲學家；玩家找到 Taalo Shield 時）
- **一律用「塔洛族」譯名**

## 四、相關遺物

- **Taalo Shield**（塔洛防護罩）——理論上能免疫心靈控制的裝置藍圖／碎片
