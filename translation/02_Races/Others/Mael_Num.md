# 梅努族 Mael-Num

> **性質**：感知聯盟倖存者；教義戰爭期間駕艦隊逃離、去向不明。無對話，只在 lore 中提及。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **梅努族** |
| 英文名 | Mael-Num |
| 陣營 | 感知聯盟時代（教義戰爭時逃離） |
| 母星 | 不明 |
| 生理特徵 | 不明 |
| 文明類型 | 感知聯盟成員 |
| 科技水平 | 中高（能建造能逃離戰場的艦隊） |
| 特殊能力 | 無 |

## 二、歷史概要

- **感知聯盟成員**
- 從蟾亞統治中倖存
- **在烏寬教義戰爭爆發後**，決定不參與內戰
- **駕艦隊集體逃離**銀河已知區域
- **去向不明**——可能在銀河邊緣、可能在其他星系
- Dnyarri 統治期間，曾被命令與烏寬一起消滅 Drall

## 三、對翻譯的意義

- **遊戲中無 Mael-Num 對話**
- 名字可能在**談感知聯盟史或烏寬分裂史**時出現
- **一律用「梅努族」譯名**
