# 布維族 Burvixese

> **性質**：龜狀高科技愛好和平種族；於西元 2142 年被 Kohr-Ah 軌道轟炸滅絕。無對話，只在 lore 中提及。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **布維族** |
| 英文名 | Burvixese |
| 陣營 | 已滅絕 |
| 母星 | Arcturus 1（大角星 1） |
| 生理特徵 | **龜狀** |
| 文明類型 | 高科技、愛好和平 |
| 科技水平 | 高（尤其 HyperWave 通訊） |
| 特殊能力 | **HyperWave 通訊技術**（偏好用通訊替代建艦） |

## 二、歷史概要

- 高度發達的和平文明
- **偏好 HyperWave 通訊**替代艦艇建造——這是他們的哲學：**用交流建立盟友，不用武力**
- 曾透過 HyperWave 與 **Utwig、Gg、Druuge** 等族接觸
- **2142 年被 Kohr-Ah 軌道轟炸滅絕**
- **元凶**：**Druuge** 用他們知曉的 Burvixese HyperWave 廣播位置**誘導 Kohr-Ah** 前來攻擊（Druuge 因此可佔用 Burvixese 遺留的技術）

## 三、對翻譯的意義

- **遊戲中無 Burvixese 對話**
- 名字在**其他族的敘事對白裡出現**（尤其談到 Druuge 陰謀或 Kohr-Ah 屠殺史）
- **一律用「布維族」譯名**
