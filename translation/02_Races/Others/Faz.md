# 法茲族 Faz

> **性質**：感知聯盟成員；第一個選擇 Fallow Slave 護盾自封的種族。無對話，只在 lore 中提及。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **法茲族** |
| 英文名 | Faz |
| 陣營 | 感知聯盟時代 → 已無獨立行動 |
| 母星 | 不明 |
| 生理特徵 | 不明 |
| 文明類型 | 感知聯盟成員 |
| 科技水平 | 中高（能建造軌道自封護盾） |
| 特殊能力 | 無 |

## 二、歷史概要

- **感知聯盟成員**
- 蟾亞統治結束、烏寬分裂為兩派後
- **第一個選擇自封於 Fallow Slave 護盾中的種族**——這個選擇後來成為烏寬克澤札對待部分被征服族的模板
- 現況：仍在護盾內，與外界完全隔絕

## 三、對翻譯的意義

- **遊戲中無 Faz 對話**
- 名字可能在**談 Fallow Slave 制度來源**時出現
- **一律用「法茲族」譯名**
