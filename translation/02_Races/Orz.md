# 歐茲族 Orz

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **歐茲族** |
| 英文名 | Orz |
| 陣營 | 中立 → 敵對（追問 Androsynth 話題時） |
| 母星 | Gamma Vulpeculae 1（狐狸座γ 1，**原為 Androsynth 母星所在**） |
| 生理特徵 | **非傳統三維生物**——來自高維度空間（*Below* 或 *Outside*）的**單一超自然存在於真實空間所伸出的「手指」（*Fingers*）** |
| 文明類型 | 超維度存在（不適用一般文明分類） |
| 科技水平 | 不明（維度技術） |
| 特殊能力 | 星號詞語操縱、旋轉榴彈砲、太空探險隊「Space Marines」 |

## 二、歷史

**起源**：**極度神秘**——**不屬於這個維度**。

**重要事件**：
- **SC2 開場前不久** **突然出現於狐狸座**——**該區域原為 Androsynth 母星所在地**
- **與 Androsynth 集體神秘失蹤完全重合**
- 表現出**極度熱情、樂天且充滿童趣的表面性格**
- **友好外表下隱藏著無法理解的異次元捕食者本質**
- **追問 Androsynth 去向時瞬間敵化**

**與其他種族關係**：
- **警戒者**：**Arilou（阿麗露）**——阿麗露知道歐茲的真相並警告地球
- **神秘關係**：Androsynth（可能被歐茲帶走或被歐茲「取代」）
- 對玩家：預設友好，觸發雷區時瞬間敵化

## 三、性格分析

**共同人格核心**：**表面極度熱情童趣＋底層異次元捕食者**——**兩個人格瞬間切換**。

**表面（預設）**：
- 過度熱情、雀躍、童趣
- 大量疊字、感嘆
- 星號詞語滿天飛

**觸發雷區後**：
- 極度冰冷
- 帶敵意與殺意
- 星號詞彙變為沉重

**價值觀**：
- 最重視：**\*玩耍\*（實際是維度侵蝕／捕食）**
- 最忌諱：**Androsynth 話題**
- 最擅長：以「\*派對\*」「\*快樂野餐\*」等語言掩蓋恐怖真相

**文化特色**：
- 語言使用**雙重意義**——表面天真，底層恐怖
- 大量 **\*星號包住的情緒詞\***
- 對三維生物的視角**扭曲**

**深層心理**：他們**不真的理解**（或不在乎）三維生物的視角——他們的「友好」是異次元存在的「玩耍」，可能對三維生物造成致命傷害。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | 中等，帶雀躍節奏 |
| 正式程度 | 極不正式、童趣 |
| 幽默程度 | 表面高（觸發雷區後全無） |
| 情緒表達 | **兩極切換** |
| 特殊語法 | **\*星號詞語\*** 貫穿全部對白（極重要） |

### 自稱

**嚴禁使用單純「我」或「我們」！** 必須帶歐茲特色：

- **Orz**（單／複數皆用）
- **Orz們**、**Orz 覺得**
- **從\*底下\*來的 Orz**（詩意）

### 對玩家的稱呼

- **\*露營者\***（*campers*）
- **\*新前輩\***（*new boys*）
- **\*快樂野餐夥伴\***（*happy campers*）
- **\*傻牛牛\***（*silly cows*）

### 核心詞彙／口頭禪（**必須保留星號格式**）

| 原文 | 中譯 | 語意 |

| `*camper party*` | `*野餐派對*` | 集會 |

### 情緒觸發雷區

- 遇到**追問 Androsynth 去向** → **瞬間冰冷、敵化**；星號詞彙從歡樂變沉重
- 遇到**談 Arilou** → 微妙（Arilou 知道他們的真相）
- 遇到**談 Below、Outside、Space** → 進入詩意但危險的狀態

## 五、中文化翻譯規則

**翻譯時應做（極重要）**：
- **保留星號格式 `*詞語*`**——這是原作標誌，絕不去掉
- 星號內詞語**中譯**（如 `*happy campers*` → `*快樂野餐夥伴*`）
- **保留怪異詞序**——不要順化
- **嚴禁**使用「我」「我們」——用「Orz」「Orz們」
- **兩階段切換**要明顯（表面歡樂 / 底層冰冷）

**翻譯時應避免**：
- **絕不移除星號**（會失去原作 icon）
- 現代口語
- 讓歐茲顯得只是搞笑（他們有真實的恐怖底層）
- 「更正」他們的怪異表達（那正是他們的語言特色）

**推薦語氣詞彙庫**：\*快樂\*、\*果汁\*、\*泡泡\*、\*空間\*、\*底下\*、\*沉重\*、\*滑順\*、\*派對\*、\*傻牛牛\*、\*漂亮\*、\*跳舞\*、\*發芽\*、\*玩耍\*、Orz、Orz們、超級、哈囉極了

## 六、對話範例

### 範例 1：表面熱情
- **原文**：`Hello extremely! I hope you like to *play*. Some *campers* are not so good for *games*.`
- **建議譯文**：`超級哈囉！Orz 希望你喜歡\*玩耍\*。有些\*露營者\*不太適合\*遊戲\*呢。`
- **翻譯理由**：「Hello extremely」→「超級哈囉」保留怪異順序；「I hope」→「Orz 希望」用第三人稱替代「我」；星號詞語保留

### 範例 2：觸發雷區
- **原文**：`Why do you ask about *Androsynth*? That is NOT *happy*! You are making Orz very *heavy*!`
- **建議譯文**：`你為什麼要問起\*安卓辛斯\*？這可一點都不\*歡樂\*！你正在讓 Orz 感到非常\*沉重\*！`
- **翻譯理由**：「NOT」用大寫式的「一點都不」對應憤怒；`*happy*` 保留星號；用「讓 Orz 感到」代替「讓我感到」
