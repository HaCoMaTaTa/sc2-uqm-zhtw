# 普恩族 Pkunk

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **普恩族** |
| 英文名 | Pkunk |
| 陣營 | 中立 |
| 母星 | Gamma Krueger 1（克魯格γ 1，原創星群） |
| 生理特徵 | **鳥人**——類似翼哈特族但體型較小、氣質輕盈 |
| 文明類型 | 靈修狂熱＋新時代（New Age）嘻皮風 |
| 科技水平 | 中等 |
| 特殊能力 | 戰艦有神秘再生能力（自稱因為「輪迴轉世」） |

## 二、歷史

**起源**：**翼哈特族的神秘靈修分支**——從翼哈特中分離出去，走上完全不同的靈性道路。

**重要事件**：
- 從翼哈特族分離
- 發展出**輪迴轉世（Reincarnation）、宇宙大愛、氣場（Aura）** 為核心的靈修文化
- **SC2 開場** 正與**蛛狂族（Ilwrath）交戰中**——因為 Dogar & Kazon 命令蛛狂族攻擊普恩；普恩雖天性愛好和平但被迫應戰
- 對玩家極友好——**善良且樂於幫助的種族**，友誼值得爭取

**與其他種族關係**：
- 遠親：**翼哈特族**（分離已久）
- 敵：**蛛狂族**（現正交戰）
- 友：對玩家極友好

## 三、性格分析

**共同人格核心**：**極度樂天＋狂熱靈修＋神經質＋嘻皮風**——把一切都用「宇宙大愛」與「氣場」解釋。

**價值觀**：
- 最重視：**宇宙大愛、靈魂連結、氣場、輪迴**
- 最崇尚：**和平、包容、預言**
- 最不理解：暴力（雖然被迫抵抗蛛狂）

**文化特色**：
- **新時代靈修**風格（水晶、氣場、宇宙一體、靈魂）
- 預言家式風格——但預言的可靠性極不穩定
- **輪迴轉世**信仰：戰敗死亡對他們是快樂的轉世之旅
- 語速極快、邏輯跳躍

**深層心理**：**永遠樂觀**——即使被蛛狂族攻擊，他們也用「這是靈魂的試煉」解釋。翻譯時要保留這種**表面靈修下的真實脆弱**（他們其實是被迫的和平者）。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | **極快**、邏輯跳躍 |
| 正式程度 | 極不正式、嘻皮 |
| 幽默程度 | 有（來自靈修狂熱的荒謬感） |
| 情緒表達 | **持續的樂觀振奮** |
| 特殊語法 | **靈性詞彙**、氣場／水晶／大愛、預言式宣言 |

### 自稱

- **愛與光的散播者**、**快樂的普恩**
- **靈魂之聲**
- **宇宙一體之見證者**
- **輪迴之見證者**

### 對玩家的稱呼

- **親愛 Friend**、**老兄**
- **美麗的靈魂**、**光之兄弟**
- **宇宙的旅人**
- **有著紫色氣場的朋友**（帶新時代玄學）

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| Cosmic aura | 宇宙氣場 | 隨時 |
| Reincarnation | 輪迴（轉世） | 談死亡 |
| Higher consciousness | 更高意識 | 談靈修 |
| Love / Light | 愛 / 光 | 隨時 |
| Vibration | 振動 / 振頻 | 談氣場 |
| Feel the love | 感受愛 | 招牌 |
| Prophecy | 預言 | 談預測 |

### 情緒觸發雷區

- 遇到**任何話題** → 用「更高力量」「宇宙一體」「大愛」解釋
- 遇到**談蛛狂族戰爭** → 稍微暗淡（但仍樂觀）
- 遇到**談翼哈特族** → 遠親感、有點懷念
- 遇到**戰鬥死亡** → **快樂的接受**（因為是輪迴）

## 五、中文化翻譯規則

**翻譯時應做**：
- **語速快、跳躍**——句子不完整、多個想法跳躍
- 大量**靈性詞彙**（氣場、振動、輪迴、更高意識、宇宙、愛、光、紫光、水晶）
- 用「老兄」「朋友」等親暱稱呼
- 保留**表面樂觀下的脆弱感**

**翻譯時應避免**：
- 太正式（他們是嘻皮）
- 太現代網路口語（雖是嘻皮但仍在 SC2 世界觀內）
- 弱化他們的樂觀（他們**永遠**樂觀）
- 讓普恩顯得深沉（他們是浮浮的、不深沉）

**推薦語氣詞彙庫**：老兄、朋友、宇宙、氣場、振動、大愛、光、輪迴、水晶、紫光、宇宙一體、感受、能量、靈魂、綻放、流轉、太美了

## 六、對話範例

### 範例 1：新時代式問候
- **原文**：`Hey brother! Your cosmic aura is glowing with purple energy today! Feel the love flowing through the void!`
- **建議譯文**：`嗨，老兄！你今天的宇宙氣場正散發著璀璨紫光呢！感受那流淌於虛空中的愛吧！`
- **翻譯理由**：「Hey brother」→「嗨，老兄」保留嘻皮親暱；「cosmic aura...purple energy」→「宇宙氣場...璀璨紫光」加強新時代玄學感；「Feel the love」→「感受那……愛吧」保留招牌感

### 範例 2：面對死亡（樂觀）
- **原文**：`If we die today, our souls simply flow to the next dance! Don't worry, brother!`
- **建議譯文**：`如果我們今天離去，靈魂只是流轉到下一段舞蹈！別擔心，老兄！`
- **翻譯理由**：「die today」翻「離去」保留他們對死亡的樂觀觀點；「flow to the next dance」翻「流轉到下一段舞蹈」保留靈修意象
