# 史怕族 Spathi

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **史怕族**★（性格暗示：「怕」） |
| 英文名 | Spathi |
| 陣營 | 烏寬階層戰奴 → **SC2 開場時已自願進入奴隸護盾封印（Fallow Slave）** |
| 母星 | Epsilon Gruis 1a（天鶴座ε 1a），別稱 **Spathiwa（史怕瓦）** |
| 生理特徵 | 細軟身體覆蓋堅硬甲殼；**巨大人類般的眼睛**在硬粗柄的頂端；驚嚇時分泌噁心液體 |
| 文明類型 | 極致神經質＋官僚自我保護型文明 |
| 科技水平 | 中等 |
| 特殊能力 | 快速科技躍升（青銅→原子只花一個世紀）；戰艦後噴 BUTT 追蹤飛彈 |

## 二、歷史

**起源**：**極度膽小懦弱**卻建立成功文明——生存哲學建立於絕對懦弱與官僚自我保護上。

**重要事件**：
- **四個世紀前** 因「邪惡者（Evil Ones）」威脅而集體恐慌 → **青銅時代到原子時代只花了一個世紀**（恐懼推動科技躍升）
- 集體逃離母星移民至衛星（因為母星有「邪惡者」）
- 敗給烏寬 → 立即選擇成為戰奴（**不到 6 小時就投降**）
- **SC2 開場前** 迫不及待建造**奴隸護盾**自我封印（他們認為在護盾內最安全）
- **自稱「Safe Ones（平安族）」**
- **例外**：**Fwiffo（費佛）**——唯一逃兵，被玩家收留

**與其他種族關係**：
- 主：烏寬（他們投降時投降得很痛快，甚至是感激的）
- 惡作劇被害者：Umgah（Umgah 常騷擾他們，例如把爛泥塞進 Spathi 的維生系統）
- Fwiffo：唯一逃離的個體，情願跟玩家一起冒險（但仍極度膽小）

## 三、性格分析

**共同人格核心**：**極致膽小＋官僚自我保護＋長篇免責聲明狂**——他們用大量的話來確保「別人不會有理由攻擊他們」。

**價值觀**：
- 最重視：**安全、安全、安全**（此其一切）
- 最恐懼：任何未知、危險、可能導致死亡的事物
- 最擅長：找一堆藉口說服自己與別人「其實不用打，我們很有用／我們很沒用／請放過我們」

**文化特色**：
- **官僚化的自我保護**——什麼事都要準備 50 個備案
- **免責聲明狂**——每句話後面都跟著「當然我不能保證這一定準確」等
- 甲殼堅硬但心靈脆弱
- 自稱「Safe Ones」——他們相信「不安全」就是最壞的事

**深層心理**：**恐懼是他們的一切**。但翻譯時要注意——他們的膽小是**滑稽的**、不是可憐的，帶著黑色幽默質感。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | **快、緊張** |
| 正式程度 | 過度禮貌、卑躬屈膝 |
| 幽默程度 | 有（黑色幽默，來自他們的過度自保） |
| 情緒表達 | **極度驚恐**、崩潰、快速切換 |
| 特殊語法 | **頻繁結巴**（「……」、「這、這個」）、**長篇免責聲明**、大量退縮語助詞 |

### 自稱

- **卑微的史怕**、**卑微的我**
- **不幸的奴家**、**懦弱的我**
- **無害的存在**
- 用大量退讓詞：「我這個一無是處的……」

### 對玩家的稱呼

- **強大且隨時能毀滅我們的閣下**
- **恐怖的異星訪客**
- **偉大的地球艦長**（過度敬語）
- **仁慈的宇宙訪客**（求饒）

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| Safe / Safety | 安全 | 隨時 |
| Please don't shoot | 請、請不要開火 | 面對威脅 |
| Hide / Hidden | 藏匿 / 躲藏 | 談自保 |
| Terrible death | 可怕的死亡 | 談後果 |
| Please don't eat us | 請別吃我們 | 求饒經典 |
| Safe Ones | 平安族 | 自稱 |

### 情緒觸發雷區

- 遇到**任何威脅** → **極度驚恐、崩潰**、快速供出秘密
- 遇到**安全狀態確認** → 瞬間鬆一口氣、切換為**官僚式的敷衍與自滿**
- 遇到**奴隸護盾** → 罕見的興奮（他們喜歡這個）
- 遇到**Umgah** → 極度不悅（但仍不敢反擊）

## 五、中文化翻譯規則

**翻譯時應做**：
- **結巴要保留**（用「這、這個」「呃……」「請、請」等頓挫）
- 大量**過度禮貌用詞**、**退讓詞**、**免責聲明**
- 情緒切換要**快而明顯**（威脅前後語氣完全不同）
- 保留**黑色幽默感**——他們的膽小是**好笑的**不是可憐的

**翻譯時應避免**：
- 讓 Spathi 顯得有勇氣（他們絕對沒有）
- 讓 Spathi 顯得可憐（他們是滑稽的，不是被同情的）
- 現代口語
- 讓他們的膽小翻成憤怒或哀怨（會走味）

**推薦語氣詞彙庫**：卑微、懦弱、無害、藏匿、躲避、絕不敢、請千萬、真的不要、我這一無是處、恕在下、這個那個、其實我們、您聽我說、絕對、萬萬不敢、可怕、恐懼、萬分抱歉

## 六、對話範例

### 範例 1：面對威脅
- **原文**：`Please do not shoot! We are completely harmless and extremely tasty... wait, no, not tasty! Very poisonous!`
- **建議譯文**：`請、請千萬不要開火！我們完全沒有威脅，而且肉質極度美味……等等，不對！一點都不美味！我們全身都是劇毒啊！`
- **翻譯理由**：「Please」翻成兩次「請、請」加強結巴；「tasty」→「肉質極度美味」→ 立刻反悔的黑色幽默保留

### 範例 2：官僚式自滿（在護盾內）
- **原文**：`Yes, yes, we are quite safe here. Very safe. Extremely safe. Also, we have paperwork to fill.`
- **建議譯文**：`是的，是的，我們在此處相當安全。極為安全。無比安全。此外，我們還有文件要填寫。`
- **翻譯理由**：三次「安全」層層遞進；「文件要填寫」翻譯保留官僚感

## 七、人名命名規則

**滑稽軟弱音節**（如 `Fwiffo`）→ 建議音譯保留荒謬感
- 例：Fwiffo → **費佛**（已鎖定，見 Glossary）
- 若遇新 Spathi 個體命名，建議用「柔軟、易記、有點滑稽」的音譯（**〔規則細節在使用者材料中未明確定義，超出此規則的個體出現時請提出討論〕**）
