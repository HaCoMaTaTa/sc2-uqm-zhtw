# 星系與星球 Star Systems

> **本檔涵蓋**：SC2 遊戲中重要的星系、恆星、與星團的名稱與所屬。所有星系名以**中華民國天文學會譯名**優先，其次採用手冊譯名；對純虛構星系採**音譯**。

## 一、太陽系（Sol System）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **太陽系** |
| 英文名 | Sol / Sol System |
| 所屬 | 人類母星系 |
| 遊戲角色 | 玩家出發起點；地球在此系；星際基地繞地球運轉 |
| 相關文件 | [Planet_Types.md](Planet_Types.md) 地球條目、[Universe_Overview.md](../01_World_Lore/Universe_Overview.md) |

**主要行星**：**地球（Earth）**——第 3 行星；**冥王星（Pluto）**——第 9 行星，費佛的起點

## 二、船帆座（Vela / Alpha Velae）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **船帆座**（星座）／**微拉**（單一恆星時） |
| 英文名 | Vela / Alpha Velae |
| 所屬 | 恩澤伐特殖民地所在 |
| 遊戲角色 | **玩家出身地**——白矮星微拉的第 2 行星就是恩澤伐特（Vela II / Unzervalt） |
| 相關文件 | [Human_Faction.md](../01_World_Lore/Human_Faction.md) |

**歷史**：巴頓艦長在此發現先驅者遺跡、建立殖民地、20 年後駕先驅者號返航地球。

## 五、勢力範圍（Sphere of Influence）

- 每個活躍種族在星系圖上有一個**影響圈**（Sphere of Influence）
- 圈內遭遇該族艦隊機率高
- 圈可**擴張、收縮**——會反映故事進展

**翻譯要點**：**Sphere of Influence** → **影響圈**（v0.2 §4）

## 翻譯要點

- **中華民國天文學會譯名**優先（船帆座、參宿四、南河三、大角星…）
- 虛構星系採音譯（Zeeman-Vela → 日曼-微拉、Delta Crateris → 巨爵座 δ）
- 星座名 + 希臘字母 → 保留希臘字母（如「船帆座 α」、「狐狸座 γ」）
- 具名行星（如恩澤伐特 Unzervalt）用**音譯**
