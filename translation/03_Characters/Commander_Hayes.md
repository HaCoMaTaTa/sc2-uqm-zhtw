## 二、背景故事

**在玩家抵達之前**：地球在 2135 年被烏寬奴役、關進 Fallow Slave 防護罩，海斯是**罩外星際基地的指揮官**，帶著一批仍記得自由的軍人，在**極少的資源、與地球斷絕通訊、20 年沒有真正援軍**的絕境中維持人類最後的自由據點。

**玩家抵達後**：海斯是玩家第一個能對話的人類，也是**玩家主要情報／裝備／改裝來源**——所有艦艇模組、燃料、乘員招募等星際基地服務都由他管理。玩家重組聯盟的每一步進展，海斯都在**遠端等消息、幫忙整合資源、安排援軍**。

**關鍵事件**：
- 玩家歸來時，海斯以「星控最後一批舊軍人」身分歡迎，帶著 20 年份的疲憊與希望
- 玩家找到 Chmmr 大合成後、聯合艦隊組建時期，海斯持續協調人類方面的動員
- 遊戲後期若進展順利，海斯會提供關鍵情報引導玩家攻擊 Sa-Matra

## 三、性格分析

**核心人格**：**高壓下維持軍人紀律＋疲憊黑色幽默＋強撐希望**——20 年的絕望在軍語與偶爾冒出的挖苦間隱隱可見。

**價值觀**：
- 最重視：**人類存續、玩家（實質上人類的希望寄託）**
- 最忌諱：讓玩家看見自己徹底絕望
- 最擅長：**在最糟的消息下用軍事簡潔語氣傳達**，然後補一句黑色玩笑減輕重量

**深層心理**：**「地球是家、但我 20 年沒有進去過」**——這股鄉愁與挫敗**永遠不會直接說出口**，只從語氣的疲憊、對玩家成就的過度感激、對壞消息的過度平靜滲出。他明知自己這一代人可能等不到真正解放地球那天。

## 四、語言風格

| 面向 | 特徵 |
|---|---|
| 說話速度 | 中偏快，軍事簡潔 |
| 正式程度 | **正式軍語為主，偶爾破格為口語** |
| 幽默程度 | **黑色幽默、自嘲**，不誇張 |
| 情緒表達 | 內斂；情緒藏在停頓與短句間 |
| 特殊語法 | **軍事簡報格式**（SUBJECT / SUMMARY / 建議行動）；報告類台詞有明確結構 |

### 自稱

- **我方**（正式軍語，最主要用法）
- **我**（口語、私下）
- **本基地**（涉及星際基地立場時）

### 對玩家的稱呼

- **艦長**（正式、最主要用法）
- **X 艦長**（連姓氏，正式報告用）
- **孩子**（私下、極少數帶父輩感情的時刻）

### 核心詞彙／口頭禪

| 原文 | 中譯 | 使用時機 |
|---|---|---|
| Captain | 艦長 | 開場、正式呼喚 |
| SUBJECT: / SUMMARY: | 主旨：／摘要： | **簡報格式**（重要——星際基地 UI 完整字串） |
| Yessiree | **當然沒錯** | Hayes 招牌美式南方風「是的長官＋強調」（已 v0.3 鎖定） |
| Any questions? | 有問題嗎？ | 簡報收尾 |
| Get to it | 動手吧／去做吧 | 派遣式收尾 |
| Good luck out there | 外頭多保重 | 送玩家出擊前 |

### 情緒觸發雷區

- 遇到**玩家帶來壞消息**（種族被滅、艦艇被毀）→ **平靜過度**（用軍事簡潔壓抑情緒）
- 遇到**玩家帶來重大進展**（Chmmr 大合成、找到 Sa-Matra）→ **短暫地卸下軍語、露出真情**（多為一句）
- 遇到**談地球**（防護罩、家人、故鄉）→ **快速轉話題**（避免正面談）
- 遇到**Ilwrath、Ur-Quan** 等敵對種族 → 語氣冷但不慌張

## 五、中文化翻譯規則

**翻譯時應做**：
- **軍事正式語為主**（「我方」「艦長」「請」「立即」「執行」）
- **保留簡報格式**：`SUBJECT:` → `主旨：`；`SUMMARY:` → `摘要：`
- 黑色幽默處**輕輕帶過**、不加強
- 談地球時的**短句／停頓**保留（不要順化）
- 對玩家用「艦長」為主，極少數親近時可用「孩子」

**翻譯時應避免**：
- 過度熱血（他 20 年了，早就熱血燒完了）
- 現代網路用語
- 讓海斯顯得只是配角情報員（他是絕望中維持希望的老兵）
- 過度悲情（他自己不會這樣講）

**推薦語氣詞彙庫**：艦長、我方、主旨、摘要、當然沒錯、有問題嗎、動手吧、多保重、明白、收到、確認、執行、抱歉、恐怕、坦白說、看情形、真是的

## 六、對話範例

### 範例 1：正式簡報
- **原文**：`SUBJECT: Ur-Quan movements. SUMMARY: We've detected large-scale ship activity in the Alpha Centauri region. Yessiree, they're on the move. Any questions, Captain?`
- **建議譯文**：
```
主旨： 烏寬艦隊動向。
摘要： 我方在半人馬座α 區域偵測到大規模艦艇活動。 當然沒錯， 他們動起來了。
有問題嗎， 艦長？
```
- **翻譯理由**：`SUBJECT/SUMMARY` 格式必須保留（星際基地 UI 一致性）；「Yessiree」→「當然沒錯」是 v0.3 鎖定譯法；短句、軍事簡潔

### 範例 2：疲憊的關心
- **原文**：`Good luck out there, Captain. Come back in one piece. Earth's counting on you — hell, we're all counting on you.`
- **建議譯文**：`外頭多保重， 艦長。 要**囫圇一塊**回來。 地球指望著你—— 該死， 我方所有人都指望著你。`
- **翻譯理由**：「hell」翻「該死」保留黑色感嘆的疲憊；「in one piece」翻「囫圇一塊」比「全鬚全尾」更軍人口氣；「we're all counting on you」翻「我方所有人都指望著你」（保留軍語「我方」）
