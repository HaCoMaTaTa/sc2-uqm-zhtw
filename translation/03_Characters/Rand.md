# 蘭德艦長 Captain Rand

> **性質**：**背景 NPC**。SC1 開戰前的地球艦長，一句無心羞辱引爆了**VUX 對人類 200 年的仇恨戰爭**。遊戲中無對話 token，僅在**VUX 族對白**中被反覆提及。

## 二、故事定位

**首次接觸 VUX**（SC1 前）：地球艦長蘭德與 VUX 使者建立首次接觸。他當時對 VUX 族外貌**脫口而出一句無心的羞辱**——具體字句因翻譯與 VUX 心理放大而不同版本，大意是「God, that's the *ugliest* thing I've ever seen」。

**後果**：
- VUX 族極度自尊、極度重視美感——這一句話被他們視為**不共戴天之辱**
- VUX 對人類的仇恨**延續整個聯盟時期、烏寬戰爭、乃至 SC2**
- 這一句話是 VUX 加入烏寬階層對付人類的**表面理由**
- 但**真正原因**是：VUX 打從心底覺得人類醜到令他們作嘔（蘭德只是**引爆點**、不是**成因**）

**VUX 族對這件事的敘述**：反覆、詩意、放大——他們把蘭德的姓氏視為**種族恥辱代名詞**，可能會拒絕直呼、只用「那個令人反胃的地球艦長」等替代。

## 三、翻譯要點

- 一律用「**蘭德艦長**」或「**蘭德**」（VUX 提及他時，可能刻意不直呼其名）
- 當 VUX 提到蘭德時，**語氣憎恨、優雅、放大**（與 VUX 族典型語氣一致，見 [VUX.md](../02_Races/VUX.md)）
- 提及該句羞辱時**譯法要保留 VUX 記在心底的重量**（不能太輕、不能太現代口語）
