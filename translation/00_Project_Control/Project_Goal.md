# 專案目標 Project Goal

## 一、專案定位

將 **Star Control II（The Ur-Quan Masters / UQM MegaMod）** 的英文遊戲文本翻譯為**繁體中文（台灣用語）**。

## 二、翻譯目標優先順序

1. **語意忠實** — 讀者理解到的意思要跟原文一樣
2. **角色人格一致** — 同一個種族／NPC 講話還是同一個角色
3. **世界觀還原** — 1990 年代美式科幻／太空歌劇的氛圍
4. **在地化通順** — 台灣玩家讀起來自然順口
5. **幽默與情緒保留** — 原文有笑點／諷刺／恐懼要傳達到

當這幾項衝突時，順序為：**1 > 2 > 3 > 4 > 5**。

## 三、翻譯範圍

| 資產 | 位置 | 範圍 |
|---|---|---|
| 種族對話 | `uqm-work/translations/*.zh-TW.json` | 27 族 × 每族一份對話樹（主要工作量） |
| 遊戲字串 | `uqm-work/translations/gamestrings.zh-TW.json` | UI、選單、系統訊息 |
| 星圖／星系名 | `gamestrings.zh-TW.json` 內 | 依「星圖交叉參照規則」處理 |
| 艦艇名／艦艇描述 | 遊戲內 UI | 依鎖定表 |
| 開場／結局旁白 | 需再確認位置 | 敘事文學風格 |

**不翻譯的東西**：`#(TOKEN_NAME)` 標記、原文字型檔案、二進位資源。

## 四、非目標（避免範疇蔓延）

- ❌ 不改動遊戲玩法／劇情
- ❌ 不翻譯 RPG Resource Guide 或英文原著手冊本身
- ❌ 不添加原著沒有的世界觀設定
- ❌ 不修改 UQM 引擎程式碼（除非為了 CJK 字型顯示，那屬另一支專案 `uqm-work/`）

## 五、成功指標

- 全遊戲通關無亂碼、無爆版
- 同一種族的對話在不同檔案裡讀起來仍是同一個角色
- 玩家看得懂、笑得出來（該笑的時候）、感受到該有的恐懼／莊嚴／悲傷
- 專有名詞跨檔案 100% 一致（可用 CI 檢查）
