# Forbidden Translations 禁止譯法

> **本檔功能**：明確列出**不允許使用的中文譯法**，避免翻譯者（含 AI）沿用舊譯或使用者《敘事語言學指南》的變體。
> **權威理由**：這些譯法要嘛與 shipped v0.3 產品衝突（會破壞既有翻譯）、要嘛在 Phase 8 詞彙表整合時被明確剔除。
> **檢查工具**：`Fixed_Terms.csv` 加上此表可寫成 CI Python 腳本，掃描 `translations/*.json` 是否含禁止字串。

## 五、風格禁忌（來自 v0.4 提詞 §9.3）

### 5.1 醫學／生物學術語（罵詞語境）

**禁止使用**（改用口語）：

| 禁止 | 應改為 |
|---|---|
| 陽痿 | 硬不起來 / 蔫 / 軟趴趴 |
| 雌性個體 | 女性同胞 |
| 非功能性生殖器 | 廢物 / 命根子 |
| 淌鼻涕 | 流鼻涕 |

### 5.2 書面語／文言（不合日常口語）

| 禁止 | 應改為 |
|---|---|
| 爾艦 | 你艦 |
| 汝 | 你 |
| 淌 | 流 |

### 5.3 中國化用語（保留繁體字面但非台灣口語）

| 禁止 | 應改為 |
|---|---|
| 蔫（作動詞用時） | 軟趴趴 / 硬不起來 |

### 5.4 直白翻譯英文生造俚語

**禁止**：直接翻英文構詞的俚語，需先找**台灣情境對應**：

| 禁止（字面直翻） | 應改為（台式對應）|
|---|---|
| 屋頂兔（roof-rabbit）| **小兔崽子** |
| 化為蒸氣（vapor city）| **灰飛煙滅** |
| 驢子口臭（donkey breath）| **臭嘴巴** |
| 屁股被轟爛（butt blasted）| **屁滾尿流** |

## 六、空格排版禁忌（v0.4 提詞 §9.4）

**禁止**：名詞短語被空格拆兩半

| 禁止 | 應改為 |
|---|---|
| 軟趴 貧血 一袋 腐肉 的 烏寬 | 軟趴趴貧血的**腐肉袋**烏寬 |
| 有 牛屎 癖 的 弱雞 | **愛聞牛屎**的變態弱雞 |
| 淌鼻涕 爛鼻頭 小毛球 | 流鼻涕**爛鼻頭**的小毛球 |

**規則**：空格保留在
- Lua template `<% ... %>` 前後
- CJK 與 ASCII 標點／英文之間
- 段落自然節奏處
