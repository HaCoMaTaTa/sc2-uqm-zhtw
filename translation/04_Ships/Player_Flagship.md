# 玩家旗艦與相關艦艇 Player Flagship

> **本檔專屬**：玩家駕駛的**復仇者號**（Vindicator）與其歷史前身**土柏月亮號**（Tobermoon）。這兩艘是**具名艦艇**（不是艦級名），翻譯時使用「號」字。

---

## 一、復仇者號（Vindicator）——玩家旗艦

### 基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **復仇者號** |
| 英文名 | Vindicator |
| 建造地 | **恩澤伐特**（Vela II / Unzervalt） |
| 建造方 | **先驅者機器人**（Precursor auto-builders） |
| 起造時間 | 約 2140 年代（方斯渥啟動主程式後） |
| 啟航時間 | 2155 年（巴頓艦長之死那一年） |
| 玩家可改名 | ✓（遊戲開始時可自訂船名） |

### 歷史

- **20 年前**：土柏月亮號迫降微拉二號後，探險隊發現先驅者遺跡的中央控制電腦
- **方斯渥啟動主程式**：先驅者機器人自主開始組裝一艘大型星船
- **十年建造期**：機器人日夜焊接、組裝、固定
- **建造停滯**：先驅者機器人回到洞內停機——**原料不足**、地球材料無法替代
- **簡化改造**：巴頓艦長判斷這太空船已足以**慢速巡航**、**簡便武器**、僅能容納**瘦皮猴船員艙房**
- **控制電腦移駕**：先驅者原設計不適合人類——**操縱桿三人才能扳動一個開關**、椅子床適合上古長毛巨象；巴頓命令將**中央控制電腦移出遺跡、重新定位到船上**
- **啟航**：由巴頓艦長帶隊、玩家角色任飛行員
- **繼承**：巴頓艦長於外太空戰死後，**玩家繼承指揮權**

### 遊戲中角色

- 玩家的**主場**——所有遊戲流程都圍繞這艘船
- 可**升級**（在星際基地加裝模組、武器、砲塔、燃料容量）
- 可**招募多種艦艇加入陣容**（史怕迴避者、Yehat 終結者、塞蓮穿透艦…）
- **註冊為復仇級（Vindicator class）**——這也是通用艦級名（但玩家旗艦是**具名的復仇者號**）

### 翻譯要點

- 一律用「**復仇者號**」（末尾一定加「號」字）
- **不要**與艦級名「復仇艦」（Vindicator class 通稱）混淆——後者出現在 melee UI 或參考文獻時使用
- 也**不要**與蛛狂 Ilwrath Avenger（復仇者）、Orz Nemesis（復仇者）等相似名混淆——見 [Alliance_Ships.md](Alliance_Ships.md)、[Hierarchy_Ships.md](Hierarchy_Ships.md)、[Neutral_Ships.md](Neutral_Ships.md)
- 玩家可改名——若在對話中出現玩家自訂船名，**保留玩家輸入的名稱**（不改譯）

## 二、土柏月亮號（Tobermoon）——20 年前的座艦

### 基本資料

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **土柏月亮號** |
| 英文名 | Tobermoon |
| 艦級 | 星控巡邏艦（Cruiser） |
| 艦長 | [巴頓艦長](../03_Characters/Burton.md) |
| 命運 | 2155 年於 Oort 雲邊緣**被烏寬 Dreadnought 光束擊毀**、巴頓艦長於外太空戰役中戰死 |

### 歷史

- **2134**：土柏月亮號在**日曼-微拉星雲**執行深偵察任務
- 被雌雄同體人（Androsynth）**改裝的守護神戰艦**突襲，全隊艦艇被擊碎、僅土柏月亮號倖存
- **偽死計謀**：巴頓艦長**急速航向超巨星、將核子武器投入燃料室引爆**——騙過 Androsynth 追擊
- **迫降微拉二號**：靠白矮星軌道行星修復
- **發現先驅遺跡**：由一名少尉在山洞中發現
- **齊船長駕船回地球求援**——**再也沒有回來**
- **20 年後**：巴頓艦長修復土柏月亮號、駕之陪同玩家的復仇者號返航
- **在 Oort 雲遇烏寬**：巴頓命令玩家駕先驅者號進入外太空、自己以土柏月亮號攔截敵艦
- **土柏月亮號被光束擊中、殘骸偏入 Unzervalt 航線、巴頓陣亡**

### 翻譯要點

- 一律用「**土柏月亮號**」（末尾加「號」）
- **注意**：中文手冊敘事 pp.11-20 已由使用者原 OCR 翻譯完成——見 `Reference_Material/starcontrol2_中文手冊_OCR.md`
- 提到這艘船時**多帶哀傷與敬意**（她是巴頓艦長的座艦與棺材）
