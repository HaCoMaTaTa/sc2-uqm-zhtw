# Ship Class Dossier Template

> **本檔為所有艦艇級別 dossier 的欄位範本**。每一艦級檔或分類檔內每一條目請照本節填寫。

## 標準艦艇條目格式

### 〔中文艦名〕（〔English Ship Class〕）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **〔中文名〕** |
| 英文名 | 〔English Name〕 |
| 所屬種族 | 〔連結 `../02_Races/xxx.md`〕 |
| 陣營 | 〔聯盟／階層／中立〕 |
| 尺寸級別 | 〔輕型 / 中型 / 重型 / 巨型〕 |
| 造價（Starbase RU） | 〔數字 or N/A〕 |
| 玩家可購 | 〔是／否／劇情特定〕 |

**主要武器**：〔武器名 + 中譯 + 效果描述〕

**特殊裝置**：〔裝置名 + 中譯 + 效果描述〕

**性格風格**（給對話翻譯用）：〔這艦級對應該種族的哪種情緒？例如 Dreadnought = 烏寬克澤札的冷酷高壓；Broodhome = 陳傑蘇的莊重防禦〕

**譯名沿革**：〔若有 v0.2 / v0.3 變體，說明採哪版〕

---

## 通則

- 所有艦艇級別名稱 **一律鎖定**（詞彙表 §3）——**不允許改譯**
- 提到艦艇時**保留冠詞**：「一艘無畏艦」「艘無畏艦艦隊」
- 玩家旗艦是**特殊案例**——見 [Player_Flagship.md](Player_Flagship.md)（Vindicator 級專有）
- 具名艦艇（如「土柏月亮號」）用「號」字，級名（如「無畏艦」）不用「號」
