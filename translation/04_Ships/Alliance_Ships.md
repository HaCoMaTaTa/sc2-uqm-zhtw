# 聯盟艦艇 Alliance Ships

> **本檔涵蓋**：新自由星系聯盟（New Alliance of Free Stars）成員種族的主要艦艇級別。
> **翻譯規則**：所有艦級中文名**鎖定不改譯**。個別具名艦艇（如玩家旗艦、Tobermoon）見 [Player_Flagship.md](Player_Flagship.md)。

---

## 一、晶智族 母巢艦（Chenjesu Broodhome）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **母巢艦** |
| 英文名 | Broodhome |
| 所屬種族 | [晶智族](../02_Races/Chenjesu.md) |
| 尺寸級別 | 重型 |
| 玩家可購 | ✗（在遊戲初期已被 Chmmr 大合成收編） |

**主要武器**：**Photon Crystals（光子晶體彈）**——分裂式晶體彈，可擴散攻擊
**特殊裝置**：**DOGI Fighters（DOGI 護艦戰機）**——放出小型攔截機防禦
**性格風格**：**莊重、防禦優先、儀式化**——晶智族長者風範
**譯名沿革**：v0.2 鎖定「母巢艦」

## 二、Mmrnmhrm 變形艦（Mmrnmhrm Transformer）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **變形艦** |
| 英文名 | Transformer / X-Form |
| 所屬種族 | [Mmrnmhrm 族](../02_Races/Mmrnmhrm.md) |
| 尺寸級別 | 中型 |
| 玩家可購 | ✗（在遊戲初期已被 Chmmr 大合成收編） |

**主要武器**：兩種形態間切換——**Fighter Form（戰機形態）**：雙光束速攻；**Missile Form（飛彈形態）**：追蹤導彈
**特殊裝置**：**形態轉換系統**（Turret ↔ Fighter）
**性格風格**：**機械精確、實驗性、變通**——Mmrnmhrm 工程哲學
**譯名沿革**：v0.2 鎖定「變形艦」

## 三、Chmmr 復仇艦（Chmmr Avatar）

> **注意**：SC2 中大合成完成後，Chmmr 主艦通常稱為 **Avatar**（阿凡達）——這是**大合成後的新艦種**。若手冊或原提詞用 **Avenger** 命名（舊譯「復仇號」），請保留 v0.2 譯名「**復仇號**」。實際遊戲中 Chmmr 主艦官方英文為 **Avatar**。

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **復仇號**（沿用 v0.2）；若正式標題出現 Avatar 可標註「阿凡達 / 復仇號」 |
| 英文名 | Avatar / Avenger |
| 所屬種族 | [Chmmr 族](../02_Races/Chmmr.md) |
| 尺寸級別 | 巨型 |
| 玩家可購 | ✗（大合成後專屬） |

**主要武器**：**Zapsat Laser（Zap 衛星雷射）**——巨型雷射搭配衛星支援
**特殊裝置**：**Tractor Beam（牽引光束）**——拉近目標
**性格風格**：**融合體宇宙頂級——高傲、絕對的力量感**
**譯名沿革**：v0.2 鎖定「復仇號」；若後續建詞彙表偏好 Avatar → 阿凡達，Phase 8 再議
