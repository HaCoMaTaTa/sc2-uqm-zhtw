# 先驅者遺物 Precursor Artifacts

> **本檔涵蓋**：SC2 主線劇情中的先驅者（Precursor）遺物與**銀河終極武器**。所有遺物名**鎖定不改譯**。

---

## 一、薩瑪特拉（Sa-Matra）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **薩瑪特拉** |
| 英文名 | Sa-Matra |
| 性質 | **先驅者戰爭平台**（Precursor War Platform） |
| 所有者 | 烏寬階層集團（現於 Delta Crateris） |
| 遊戲角色 | **終極目標**——玩家需組織聯軍摧毀它才能擊敗烏寬 |

**背景**：Sa-Matra 是先驅者戰爭平台，被烏寬階層當作終極武器，也是烏寬能同時**奴役半個銀河**、又**壓制內部克澤札與柯亞內鬥**的關鍵籌碼。玩家的最終戰役就是攻擊 Sa-Matra。

**翻譯要點**：一律用「**薩瑪特拉**」；不允許「薩·瑪特拉」「莎瑪特拉」等變體。

## 二、厄創（Ultron）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **厄創** |
| 英文名 | Ultron |
| 性質 | **先驅者神秘裝置**（用途無人真正確定） |
| 所有者 | [憂特族](../02_Races/Utwig.md) |
| 遊戲角色 | 憂特族的**文化核心與精神支柱**；被 Druuge 破壞後騙賣，是憂特族現今崩潰的根源 |

**背景**：憂特族擁有 Ultron 時代是他們文化**最鮮活、最躍動的黃金時期**。他們相信 Ultron 能給予宇宙洞察力。**毒賈族**在多年前從第三方得到 Ultron 後**故意破壞其中幾個關鍵組件**（見下文玫瑰球體）、再**騙賣**給憂特族。憂特在一次儀式中發現 Ultron 已失效，隨即陷入永久性的哲學崩潰。

**遊戲中的重要性**：**玩家需要幫憂特族修復 Ultron**（找回 4 個組件），才能讓憂特脫離抑鬱、加盟聯軍。

**Ultron 的四個組件**（玩家需收集）：
1. **玫瑰球體**（Rosy Sphere）——見下條
2. **Aqua Helix**
3. **Clear Spindle**
4. **Umgah Hyperspatial Terror**（Umgah 從 Sirius 帶回來的心靈裝置）

**翻譯要點**：一律用「**厄創**」；四個組件的中譯待 Phase 8 建詞彙表確認。

## 三、玫瑰球體（Rosy Sphere）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **玫瑰球體** |
| 英文名 | Rosy Sphere |
| 性質 | Ultron 的**主要組件之一** |
| 所有者 | 毒賈族（他們從 Ultron 上拆下、與其他偽造物一起賣回給憂特族） |

**背景**：這是毒賈商業陰謀的物證——他們把玫瑰球體從 Ultron 拆下、破壞 Ultron 功能，再全套「復原品」賣回去。玩家要**從毒賈族手中買回**玫瑰球體。

## 四、太陽裝置（Sun Device）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **太陽裝置** |
| 英文名 | Sun Device |
| 性質 | 先驅者能量放大裝置 |
| 遊戲角色 | 用來**加速 Chmmr 大合成**——Chmmr 的融合需 90-110 年，Sun Device 能將此壓縮 |

**背景**：Sun Device 存放於**Beta Corvi 系統**——玩家需要通過晶智族長者的引導找到它。這是解救聯盟的關鍵一步：**沒有 Sun Device 就無法及時完成 Chmmr 大合成**、玩家就沒有 Chmmr 艦隊參戰。

**翻譯要點**：一律用「**太陽裝置**」。

## 五、塔洛防護罩（Taalo Shield）

| 項目 | 內容 |
|---|---|
| 中文名（鎖定） | **塔洛防護罩** |
| 英文名 | Taalo Shield |
| 性質 | **免疫心靈控制**的裝置 |
| 遊戲角色 | 玩家需要它來對抗**Dnyarri 覺醒**的威脅——若 Dnyarri 重新獲得心靈控制能力，可能瞬間逆轉戰局 |

**背景**：由已滅絕的[塔洛族](../02_Races/Others/Taalo.md)研發，是感知聯盟時代**唯一能對抗 Dnyarri 心靈控制的技術**。塔洛族被 Dnyarri 命令其他被奴役族群消滅前，疑似接近完成一個**能將心靈防護擴散給其他族群的裝置**——這正是玩家要找到的東西。

**翻譯要點**：一律用「**塔洛防護罩**」（不要「塔洛盾」「塔洛之盾」等變體）。
