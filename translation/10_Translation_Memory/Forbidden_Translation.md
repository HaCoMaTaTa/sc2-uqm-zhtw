## 四、風格禁止字類

### 4.1 醫學術語（罵詞語境）

| ✗ 避免 | ○ 改用 |
|---|---|
| 陽痿 | 硬不起來 / 蔫 / 軟趴趴 |
| 生殖器般的東西 | 廢物 / 陽痿無膽的廢物 |
| 雌性個體 | 女性同胞 |
| 非功能性生殖器 | 廢物 / 命根子 |

### 4.2 生物學術語

| ✗ 避免 | ○ 改用 |
|---|---|
| 淌鼻涕 | 流鼻涕 |
| 分泌物 | 黏液 / 口水 |
| 排泄物 | 屎 / 大便 |

### 4.3 書面／文言（玩家 response 不宜）

| ✗ 避免 | ○ 改用 |
|---|---|
| 爾艦 | 你艦 |
| 汝 | 你 |
| 淌 | 流 |

**例外**：**極正式古語型 NPC**（烏寬克澤札「本平台」「爾等」、翼哈特「吾」「本艦」、蟾亞覺醒「爾等蟲豸」）可**保留文言**——是**該角色人格**。

### 4.4 中國化用語

| ✗ 避免（大陸口語）| ○ 台灣口語 |
|---|---|
| 蔫（作動詞）| 軟趴趴 / 硬不起來 |
| 咋辦 | 怎麼辦 |
| 特別是 | 尤其是 |
| 好像的樣子 | 好像 |

### 4.5 當代網路用語

**絕對禁止**：YYDS、GG、傻眼貓咪、崩潰、絕了、放大絕、笑死…

**理由**：SC2 是 1992 年科幻，加當代網路詞**嚴重出戲**。

### 4.6 英文生造俚語字面直翻

| ✗ 字面直翻 | ○ 台灣情境對應 |
|---|---|
| 屋頂兔（roof-rabbit）| **小兔崽子** |
| 化為蒸氣（vapor city）| **灰飛煙滅** |
| 驢子口臭（donkey breath）| **臭嘴巴** |
| 屁股被轟爛（butt blasted）| **屁滾尿流** |

## 五、格式禁忌

### 5.1 空格切分錯誤（名詞短語被拆兩半）

| ✗ 錯誤 | ○ 正確 |
|---|---|
| 軟趴 貧血 一袋 腐肉 的 烏寬 | 軟趴趴貧血的**腐肉袋**烏寬 |
| 有 牛屎 癖 的 弱雞 | **愛聞牛屎**的變態弱雞 |
| 淌鼻涕 爛鼻頭 小毛球 | 流鼻涕**爛鼻頭**的小毛球 |

### 5.2 感嘆詞被翻譯（**必須保留原文**）

| ✗ 被翻譯 | ○ 保留原文 |
|---|---|
| 凱伊！ | **Kyaiee!** |
| 海！ | **Hyai!** |
| 哈！（Shofixti 武士刀時）| **Ha!** |
| 哼嘶！ | **SNORT!** |
| 阿伊！ | **AIEE!** |
| 里啟─里啟！ | **Lykeee-lieee!** |
| 嘿嘿嘿 | **hee-hee-hee** |

### 5.3 Orz 星號詞語缺失

| ✗ 錯誤 | ○ 正確 |
|---|---|
| 快樂野餐夥伴（無星號）| `*快樂野餐夥伴*` |
| 果汁 | `*果汁*` |
| 傻牛牛 | `*傻牛牛*` |

### 5.4 星圖名沒附英文

**背景**：星圖介面是純英文，玩家看不到中文星名——**必須附英文原文**。

| ✗ 缺英文 | ○ 附英文 |
|---|---|
| 參宿四 | 參宿四（Betelgeuse） |
| 南河三 | 南河三（Procyon） |

**例外**：**同 token 區塊內第二次起可省略**；跨區塊再次出現時建議再附。

## 六、如何檢查（工具）

### 6.1 手動 grep

```powershell
# 檢查是否有簡體字混入
Select-String -Path uqm-work/translations/*.zh-TW.json -Pattern '[龙华万义从会学图无]'

# 檢查是否有 v0.4 舊譯殘留
Select-String -Path uqm-work/translations/*.zh-TW.json -Pattern '撒達許|蘇菲斯特|阿姆嘎|葉哈特|尼亞里|蘇波|德魯|梅爾諾'

# 檢查感嘆詞是否被翻譯（有中文擬音）
Select-String -Path uqm-work/translations/*.zh-TW.json -Pattern '凱伊|阿伊|里啟|嘿嘿嘿'
```
