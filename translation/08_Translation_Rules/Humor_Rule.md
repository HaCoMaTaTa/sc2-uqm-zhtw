# Humor Rule 幽默翻譯規則

> **本檔功能**：SC2 各族的**幽默類型**與**翻譯處理原則**。SC2 是一款**幽默感極重**的太空歌劇——每個種族都有獨特的幽默類型，翻譯時**保留幽默是關鍵**。
> **權威來源**：使用者《敘事語言學指南》各族章節 + shipped v0.3 各族實例 + 個人 dossier 觀察。

---

## 一、幽默的核心原則

### 1.1 保留幽默是**次要目標**（v0.4 §1 五個優先順序 §5）

**衝突時排序**：語意 > 人格 > 世界觀 > 通順 > **幽默**。

**意思**：如果無法兼顧，**寧可保留意思、放棄部分幽默**——但**盡可能兩者兼顧**。

### 1.2 幽默要「翻對層次」

SC2 的幽默有**多個層次**：

| 層次 | 說明 | 翻譯手法 |
|---|---|---|
| **表面詼諧**（字面搞笑）| 一句話讀起來就好笑 | 保留字面 + 選台灣情境對應詞 |
| **人格幽默**（角色特徵）| 該角色說話方式本身好笑 | 保留該族特徵（不順化）|
| **情境幽默**（反差／諷刺）| 前後對比、荒謬情境 | 保留節奏與轉折 |
| **元幽默**（打破第四牆）| 諷刺遊戲慣例、開發者玩笑 | 保留玩笑但**不加台灣網路用語** |

## 二、各族幽默類型與翻譯手法

> **⚠️ v0.7 全族審計後系統性補充（2026-08-15）**：本節**多族翻譯手法欄的「文言詞」用法**已在 [../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md](../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md) 中被證與原文語體不符（Yehat / Kzer-Za / Kohr-Ah / Dnyarri 覺醒），將在後續版本個別修訂。翻譯時**遇到「吾/爾/之/乃」等文言助詞的建議請對照 [Alien_Speech_Rule.md](Alien_Speech_Rule.md) §4 / §5 / §8 / §12 v0.7 警告框確認是否已停用**。目前確認 v0.7 更新完成的族：**Utwig**（本檔 §2.8 已修）。

### 2.1 修烈士族 Shofixti — **熱血搞笑**（田中）＋**冷靜穩重**（武士刀）

**幽默類型**：
- **熱血過頭**（田中每句都要 Kyaiee！）
- **姊弟反差**（武士刀嚴肅↔田中衝動）
- **英雄崇拜**（對已亡英雄「蘿蔔」的執念）

**翻譯手法**：
- **田中**：短促、驚嘆多、Kyaiee 保留原文
- **武士刀**：長句、正式、「本人再說一次哈」的**擬人化重複強調**
- **姊弟對話**：田中用「俺」、武士刀用「本人」——**性格對比一目了然**

**範例**：
```
田中：俺這就用死亡之吼殺敵！Kyaiee！
武士刀：稍安勿躁，弟弟。本人以英雄蘿蔔之名起誓，這次定殺他。
```

### 2.2 史怕族 Spathi — **膽小到極致**（費佛的荒謬）

**幽默類型**：
- **免責話術**（永遠找一個「小小的可能」逃避）
- **自我美化**（把逃跑說成「戰略性撤退」）
- **過度解釋**（明明可以說「不」，他要講三段）
- **哀嚎「拜託拜託拜託」**

**翻譯手法**：
- **超長免責頭**：「或許…或許…只是一個小小的建議…當然啦…但或許…」
- **美化詞**：戰略性撤退、稍作退避、暫時遠離
- **自稱**：**「平安族的我」**、**「一個」**、**「不才」**
- **疊字哀求**：「拜託拜託拜託」「不不不不」「咿咿咿」

**範例**：
```
或許……或許……只是一個小小的建議，當然啦，
不過或許進行一次戰略性撤退在此時此刻，呃，
從統計上來說會比較明智？
```

### 2.3 蘇菩族 Supox — **優雅有禮**＋**共生依賴**

**幽默類型**：
- **過度禮貌**（連罵人都用「恕在下直言，此舉不甚妥當」）
- **對 Utwig 過度依賴**（「若沒有 Utwig 我族將…嗯…此問題我等尚未思考過」）
- **植物意象**（用根、葉、光、養分做比喻）

**翻譯手法**：
- **極正式、優雅**：「恕在下」「有勞閣下」「敢問尊駕」
- **植物語彙**：「祝您的根得到灌溉」「願肥料流經您的根」
- **Utwig 提及**：語氣**微微沉重**（他們的老大哥）

**範例**：
```
恕在下直言，我族十分敬重貴族，
但此決定我等需先請示憂特兄長。
還請閣下賜予數日靜候之時。
```

### 2.4 陰嘎族 Umgah — **陰險詭笑**＋**惡作劇本質**

**幽默類型**：
- **hee-hee-hee 陰笑**（招牌）
- **偽善的關心**（「哎呀你受傷了嗎～我們可以幫你」實際是打算利用）
- **對其他族的惡作劇**（假扮 Spathi 之王詐騙全族、假扮 Ilwrath 邪神神諭讓 Ilwrath 屠殺無辜）
- **廣場恐懼症的荒謬**（他們是宇宙旅行者卻怕開闊空間）

**翻譯手法**：
- **hee-hee-hee 保留原文**
- **輕浮語氣**：「這位那位」「呵呵」「有意思有意思」
- **偽善詞**：「我族好意」「一片誠心」「別擔心」
- **話峰轉折**：前一句關心、後一句露餡

**範例**：
```
噢～可憐的地球艦長，看你受傷了嗎？
hee-hee-hee！我族有一劑靈藥給你……
只要你先把復仇者號的核心讓我族看一眼～
```

### 2.5 翼哈特族 Yehat — **蘇格蘭騎士**＋**中世紀武士榮譽**

**幽默類型**：
- **過度戲劇化**（每句都要莊嚴發誓）
- **舊時代口吻在太空艦艇上**（明明是宇宙飛船卻用「吾之座駕」「英勇騎士」）
- **蘇格蘭 rrrr 顫音**（原文用 "eep" "roow" 等）

**翻譯手法**：
- **文言古語**：「吾」「爾」「本艦」「氏族」「血誓」
- **騎士詞彙**：翱翔、蒼鷹、羽翼、榮譽、家門
- **感嘆詞保留原文**：Lykeee-lieee!

**範例**：
```
啊哈，勇敢的地球艦長！
命運之風將吾等聚首於此！
吾以氏族先祖之名發誓，此番共戰必名垂青史！
Lykeee-lieee！
```

### 2.6 撻伐族 Thraddash — **狂妄自大**＋**SNORT! 招牌**

**幽默類型**：
- **傲慢挑釁**（每句都想戰）
- **SNORT! 哼嗤鼻聲**（招牌）
- **「螺旋文明」的荒謬**（19 輪自我打回蠻荒，卻認為是「進步」）
- **「顧後方」的隱藏羞辱**（被烏寬邊緣化，罕見顯露）

**翻譯手法**：
- **SNORT! 保留原文** 或翻「哼！」
- **短促、多驚嘆號**：「哼！」「證明你自己！」「弱者！」
- **傲慢詞彙**：「吾等」「本族戰士」「弱小者」
- **罕見羞辱**：短句、停頓、「顧後方」不加解釋

**範例**：
```
SNORT！哼！爾等竟敢對第十九文化之戰士出言？
以戰鬥證明爾等之價值！
```

**罕見羞辱**（顯露內心）：
```
哼……他們把我們留在這裡。顧後方。哼。
```

### 2.7 蛛狂族 Ilwrath — **狂信瘋狂**＋**詛咒式禱告**

**幽默類型**：

- **禱詞口吻**：「聞我等哉」「我等祈禱」「以爾聖名」

- **無盡的褻瀆**：「肉肉人類」「可憎的凡人」「靈長類胡話」

**範例**：
```
聽哉！可怖雙煞再次降臨我等之中！
聞我等謝恩，偉大的多加與卡宗！
我等在您殘酷差遣下於異星尋得無上之樂！
```

### 2.8 憂特族 Utwig — **哲學崩潰的高知識份子集體憂鬱症**（v0.7 修訂）

> **⚠️ v0.7 重大修訂（2026-08-15）**：舊定位「憂鬱莊重」不夠準確。實證分析 Sa-Matra 對白庫，Utwig 為 **Jack Vance 式巴洛克現代英語 + Douglas Adams 式英式冷幽默**。詳見 `02_Races/Utwig.md` §四。

**幽默類型**：
- **官樣文書體 vs 存在危機**（用委員會用語討論集體自殺，自帶荒謬感）
- **學術冗長句 vs 憂鬱**（`In our attempt to balance the Doctrinal Conflict between the Kohr-Ah and the Ur-Quan we avoided the Ur-Quan`）
- **冷式自嘲**（`Ha ha, don't worry. Hey! I laughed! How could I do that?` — Utwig 對自己意外的笑聲吃驚）
- **面具規範化的官僚荒謬**（「面具規範；由基本之勞苦但必需之活動之面具至最華麗之星辰代表之容貌」）
- **1800 種面具依場合佩戴的執念**
- **兩階段人格切換**（Ultron 修復後從憂鬱轉狂喜）

**翻譯手法（v0.7 現代學者式）**：
- **現代華麗長句 + 官樣公文體**：「委員會調查」「本次通訊」「集體意見」「本項政策」
- **自稱**：**我方 / 我們憂特**（預設，官方口吻）；**悲慘的憂特族**（少量點綴）
- **稱訪客**：**你 / 你們**（預設）；**仁慈的星際旅人**（戲劇性場合）
- **感嘆詞**：**痛哉！**（Alas）、**唉**（Ugh/Sigh）—— 點綴用，勿濫用
- **✅ 對**：學術詞、心理詞、官樣文（「集體悲愴」「憂鬱誘發之淡漠」「哲學崩潰」）
- **❌ 錯**：文言古語（吾/爾/之/乃/矣/哉）—— 與原文語域不符

**範例（憂鬱期 · v0.7 現代學者式）**：
```
唉。 我方想，出於禮貌，我方應該致以一個適當的問候。
代表憂特監督者，我方衷心希望，看在你的份上，
你今天過得比我方好一些──
儘管這個祈願實在說不上什麼分量。
```

**範例（Ultron 復活後狂喜 · v0.7 現代宗教見證）**：
```
啊啊啊──！！ 它表面的每一個凹痕、每一道裂縫，都永恆銘刻在我方的靈魂之中！
把它從我方的視線移開，免得我方清空……喂！
這不是那損毀的厄創──這是先前厄創的影像！
你獲得我方永恆的感謝，善良的艦長！
```

### 2.12 梅諾商 Melnorme — **華麗商業修辭**（v0.7 update · 2026-08-18）

> **v0.7 修訂**：原範例句使用文言助詞（`之 / 乃`）與 v0.7 全族審計政策衝突。改用 **modern-formal Mandarin**（現代優雅商務體）。

**幽默類型**：
- **極正式的推銷用語**（「今日或可略作交易一二」）
- **奇長艦名**（「於所有情境必勝之艦」· `之` 為 canonical 專名保留）
- **不接受議價的冷酷**（「本商行的報價即最終價」）
- **對顏色的執念**（Rainbow World 情報值連城）

**翻譯手法**：
- **華麗優雅**：「本商行」「問候您」「今日或可」「敢問」「請容本人」
- **推銷語**：「精選」「獨到」「必勝」「稀有」「絕無僅有」「精妙」「超值」
- **拒議價定式**：「即最終價」「不接受議價」「好好考慮，仔細考慮」

**範例**（v0.7 canonical）：
```
問候您，艦長！
本人即綠光貿易官，執掌梅諾商的星艦「於所有情境必勝之艦」。
今日或可略作交易一二，如何？
```

**翻譯手法**：
- **Juffo-Wup 保留原文**
- **有機動詞**：「流動」「發芽」「萌發」「消化」「共融」
- **切換句**：「Juffo-Wup 之流動改變了……」

### 2.21 VUX — **極端自尊＋執念仇恨**

**幽默類型**：
- **極度自尊卻極容易被侮辱**（200 年前一句話結下不共戴天之仇）
- **變態的執念**（ZEX 是招牌案例）
- **對美感的極端偏執**

**翻譯手法**：
- **正式優雅**：「本將軍」「吾」「珍藏」「極品」
- **VUX 侮辱**：「肉塊生物」「令人反胃」「可憎」
- **語氣與內容的落差**：極優雅語氣說極噁心內容

### 2.22 安卓辛族 Androsynth — **雙重仇恨**

**幽默類型**：
- **對地球的恨**（被地球流放）
- **對烏寬的恨**（被烏寬短時間奴役）
- **神秘消失的哀傷**（SC2 開場已神秘失蹤）

**翻譯手法**：**罕見出現**——若有對話，兼具兩層仇恨。

### 2.23 普恩族 Pkunk — **靈修樂觀**

**幽默類型**：
- **神秘的預言**（真假難辨）
- **與蛛狂族被迫作戰的無奈**（愛好和平的鳥人被迫打仗）
- **對「更高意識」的執念**

**翻譯手法**：
- **靈修詞彙**：「意識」「頻率」「純粹之光」「涅槃」
- **樂觀語氣**：「一切終將美好」「宇宙自有其道理」
- **預言口吻**：「吾洞見……」

### 2.24 已滅絕族群

無對話——見 [Others/](../02_Races/Others/)。

## 三、跨族共通幽默類型

### 3.1 反轉羞辱（Insult Turnaround）

**背景**：v0.4 §Q5 已鎖定 5 個玩家 response 侮辱案例：

| Token | 譯文 |
|---|---|
| `no_one_insults` | 沒人敢那樣罵老子！你這缺牙雜毛硬不起來的小兔崽子！|
| `donkey_breath` | 喂臭嘴巴──再罵一句老子就炸得你灰飛煙滅！|

**翻譯手法**：直白、爽快、**用台灣口語罵詞**——**不用書面語**。

### 3.2 元幽默（打破第四牆）

**範例**：
- 塞蓮族的**「你們地球人真愛擬人化」**（諷刺遊戲設計）
- 費佛的**「幸好你保護了膽小的我」**（諷刺遊戲難度）
- 佐-佛-皮 **「Frungy is the sport of kings!」**（無理由堅持一個無厘頭）

**翻譯手法**：**保留原文的荒謬感**——不加台灣網路用語（會出戲）。

### 3.3 諷刺（Sarcasm）

**範例**：
- 費佛：「戰略性撤退」= 逃跑
- 綠光：「今日或可略作交易一二」= 我要賣你 3000 credits
- 蛛狂：「以您聖名的無情屠殺」= 屠殺無辜

**翻譯手法**：**保留原文的表層優雅／禮貌**——**不揭穿諷刺**（諷刺就是要讀者自己看穿）。

## 四、幽默的**不宜翻譯**情境

### 4.1 純語音笑話（Puns）

**背景**：英文的**同音字笑話**中文難翻。範例：

- 蛛狂族的 "Dogar" 讀音接近 "dogma"（教條）
- 佐-佛-皮的 "Frungy" 音節本身就好笑

**翻譯手法**：
- **保留原文**（讀者看得懂英文的自會發笑）
- **加譯註** `_notes` 說明音效笑話

### 4.2 遊戲外知識依賴

**背景**：某些幽默依賴當時（1992）的科幻迷懂的梗——如**「必勝之艦」**呼應星際迷航「企業號」命名慣例。

**翻譯手法**：
- **保留字面翻譯**
- 讀者若知就好、不知也不影響遊戲

## 五、絕對禁止的**幽默翻譯手法**

### 5.1 加入台灣網路用語

**絕對禁止**：
- 「傻眼貓咪」「YYDS」「GG」「不 OK」等
- **理由**：SC2 是 1992 年科幻，加當代網路詞**嚴重出戲**

### 5.2 加入時事梗

**絕對禁止**：
- 政治、新聞、名人梗
- **理由**：SC2 世界觀是 2155 年太空歌劇，時事會**破壞沉浸感**

### 5.3 過度台灣化

**絕對禁止**：
- 用「台灣國語」（如「這樣子」變「這樣子啦」）
- **理由**：SC2 是**科幻**、要**帶點正式感**——不能像鄉土劇

**例外**：**費佛**的膽小免責可略帶「拜託拜託拜託～」的**輕度台灣口語**——因為費佛的角色就是荒謬。
