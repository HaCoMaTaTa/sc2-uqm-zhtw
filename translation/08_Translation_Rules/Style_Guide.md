# Style Guide 翻譯風格指南

> **本檔功能**：規範 SC2 翻譯的**整體風格**——特別是**玩家 response** 的台式順口通則。所有種族／NPC 翻譯共通遵守本檔。
> **權威來源**：使用者 v0.4 提詞 §9「玩家 response 台式順口通則」+ shipped v0.3 shofixti.json `_notes`。

---

## 一、整體風格哲學

### 1.1 兩層人格：NPC vs 玩家

SC2 對話有**兩種說話者**，翻譯手法**完全不同**：

| 說話者 | 翻譯手法 |
|---|---|
| **NPC**（外星人角色） | **保留該族特徵**：怪異句式、獨特詞彙、種族性人格底層——**不順化** |
| **玩家 response**（艦長選項） | **貼近台灣中文母語者在同情境下自然會說的話**——**順化** |

**背景**：NPC 是異星文化，讀者期待感受到「他們是外星人」；玩家是我方角色，讀者代入自己說出來的話。

### 1.2 五個優先順序（v0.4 提詞 §1）

翻譯時遇到取捨，按以下順序決定：

1. **語意** — 意思正確、不誤導玩家
2. **人格** — 該角色（種族／個人）的說話特色保留
3. **世界觀** — 符合 SC2 setting（20 年前 Vindicator、烏寬奴役地球、感知聯盟…）
4. **通順** — 讀起來自然
5. **幽默** — 保留原文詼諧

**衝突時**：語意 > 人格 > 世界觀 > 通順 > 幽默。

## 二、玩家 response 三大情境人稱切換（v0.4 §9.1）

玩家艦長對同一個 NPC 在不同情境用**不同自稱**：

| 情境 | 自稱 | 例 |
|---|---|---|
| **正式自我介紹** | 「我是 X 艦長」/「我方」 | `i_am_captain`：「我是 X 艦長，隸屬 <盟> 旗艦 <艦>。立刻住手！」 |
| **對嗆上頭** | 「老子」/「你」/「你這」 | `no_one_insults`：「沒人敢那樣**罵老子**！**你這**缺牙雜毛硬不起來的小兔崽子！」 |
| **平和溝通** | 「我方」/「我」 | `dont_attack`：「別打了—— **我**不是烏寬！**我**是你的盟友！」 |

### 情境判斷條件（給翻譯者）

- **正式**：token 名含 `captain`、`introduce`、`am_captain`、`starship_named` → 用「我是艦長／我方」
- **對嗆**：token 名含 `insult`、`hostile`、`attack`、`limp`、`donkey`、`no_one` → 用「老子／你這」
- **平和**：token 名含 `friendly`、`greet`、`stop`、`please`、`talk`、`peace` → 用「我方／我」

### 判斷不明時

**保守選擇「我方」**——這是最中性的軍事語，不會出戲。

## 三、避免的字類（v0.4 §9.3）

### 3.1 醫學術語（罵詞語境用口語）

| ✗ 避免 | ○ 改用 |
|---|---|
| 陽痿 | 硬不起來 / 蔫 / 軟趴趴（罵人語境）|
| 生殖器般的東西 | 廢物 / 陽痿無膽的廢物 |
| 雌性個體 | 女性同胞 |
| 非功能性生殖器 | 廢物 / 命根子 |

### 3.2 生物學術語（罵詞語境用口語）

| ✗ 避免 | ○ 改用 |
|---|---|
| 淌鼻涕 | 流鼻涕 |
| 分泌物 | 黏液 / 口水 |
| 排泄物 | 屎 / 大便（依語境） |

### 3.3 書面語／文言（不合當代口語）

| ✗ 避免 | ○ 改用 |
|---|---|
| 爾艦 | 你艦 |
| 汝 | 你 |
| 淌 | 流 |
| 焉知 | 怎麼知道 |
| 曷 | 為什麼 |

> **⚠️ v0.7 重大修訂（2026-08-15，全族審計後）**：
>
> **過去允許 Yehat「吾／本艦」、Kzer-Za「吾等」、蟾亞覺醒「爾等蟲豸」等文言的白名單全數廢止**。實證分析 [sa-matra.net](https://www.sa-matra.net/quotes/) 對白庫，SC2 英文原文是 1992 年**現代英語**——**無** thou/thee/thy/wilt/hast 等古語。**8 族 dossier 曾誤標為「文言化」**，見 [../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md](../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md)。
>
> **原文的「莊嚴感」實際來自**：正式現代英語 + 抽象名詞 + 排版格式 icon（全大寫 / 全小寫 / 首字大寫 / 括號心控），**不是**古語助詞。
>
> **v0.7 後的正確作法**：
> - **Kzer-Za**：極正式現代命令體（「本平台」保留為機械化自稱，「爾等」改用「你們」/「此類生物」）
> - **Kohr-Ah**：極簡冷酷宣告 + 淨化教義詞彙（`We cleanse.` → 「我方淨化。」，不用「吾等淨化之」）
> - **Yehat**：**蘇格蘭勇士古老腔 + 鳥類擬聲 + 中世紀騎士榮譽**（不是文言；見 Braveheart / Robert Burns 風）
> - **Shofixti Tanaka**：**熱血 anime 武士 + 現代粗口 + 日式感嘆詞**（自稱「俺」為特例，Q4 已定案）
> - **蟾亞覺醒**：現代黑色villain 諂媚/心控括號 `-<CAPS>-` 命令體，**不是**文言主宰
> - **VUX**：**勢利眼傲慢 + 嘔吐感 + 現代口語毒舌**，**不是**「宮廷式文言」
>
> **玩家 response 仍一律不用文言**（未變）。

### 3.4 中國化用語（保留繁體字面但非台灣口語）

| ✗ 避免（大陸口語） | ○ 台灣口語 |
|---|---|
| 蔫（作動詞用時） | 軟趴趴 / 硬不起來 |
| 尷尬（僅指害臊） | 「這樣講很尷尬」（不用「尷」原意的「不好意思」）|
| 咋辦 | 怎麼辦 |
| 好像 → 好像的樣子 | 好像 |

### 3.5 簡體字

**絕對禁止**任何**簡體字**進入譯文。常見混入：

| ✗ 簡體 | ○ 繁體 |
|---|---|
| 龙 | 龍 |
| 华 | 華 |
| 万 | 萬 |
| 义 | 義 |
| 从 | 從 |
| 会 | 會 |
| 学 | 學 |
| 图 | 圖 |
| 网 | 網 |
| 头 | 頭 |
| 无 | 無 |
| 专 | 專 |
| 众 | 眾 |
| 车 | 車 |
| 见 | 見 |
| 说 | 說 |
| 该 | 該 |
| 谁 | 誰 |
| 难 | 難 |
| 阴/阳 | 陰／陽 |
| 长 | 長 |
| 门 | 門 |

**檢查工具**：翻譯 gate 應含簡體字 grep（見 [Consistency_Check.md](../11_QA/Consistency_Check.md) Phase 11 建立）。

### 3.6 日語漢字

**絕對禁止**日語專屬漢字（僅日語使用、繁體字典無此字）：

| ✗ 日語漢字 | ○ 繁體 |
|---|---|
| 払 | 打 / 支付 |
| 弘 | 宏 / 大 |
| 剣 | 劍 |
| 桜 | 櫻 |

**例外**：**Shofixti 角色專名保留日文**——田中（田中）、武士刀（かたな 保留漢字或音譯）、蘿蔔（だいこん）、高麗菜（キャベツ→翻）。這是刻意的日式風味，不算違規。

## 四、英文生造俚語處理（v0.4 §9.2）

**核心原則**：**遇英文構詞俚語不字面直翻**——先問「台灣情境下這個罵詞會怎麼說？」

| 英文原文 | ✗ 字面直翻 | ○ 台灣情境對應 |
|---|---|---|
| roof-rabbit | 屋頂兔 | **小兔崽子** |
| vapor city (for you) | 化為蒸氣的城市 | **灰飛煙滅** |
| donkey breath | 驢子口臭 | **臭嘴巴** |
| butt blasted | 屁股被轟爛 | **被打得屁滾尿流** |
| MORON RATHEAD | (照鎖) | **白痴鼠腦** ★ |
| Kyaiee!/Hyai! | (擬聲) | **保留原文** ★ |
| numbskull | 數字骷髏 | **笨蛋** / **腦殘** |
| space garbage | 太空垃圾 | **廢物**（如「你這廢物」）|
| slave scum | 奴隸垃圾 | **奴隸賤貨** |

**判斷步驟**：
1. 這是**英文構詞的罵詞**嗎？（如 X+ Y 兩個 Z 字組合）
2. 台灣中文有**同情境的現成罵詞**嗎？→ 用之
3. 沒有 → 造新詞（模仿台式表達）或**保留原文＋標星**（★ = 使用者已鎖定）

## 五、空格切分規則（v0.4 §9.4）

**背景**：`patch 006` 已讓 `comm.c getLineWithinWidth` 把 CJK 視為 word boundary，故**排版 wrap 不再需要 CJK 之間的空格**。空格僅保留在以下位置：

### 5.1 保留空格的情境

- **Lua template `<% ... %>` 前後** —— e.g., `我是 <% state.sis.getCaptainName() %> 艦長`
- **CJK 與 ASCII 標點／英文之間**（可讀性）—— e.g., `Ur-Quan 是 X`（Ur-Quan 是英文）
- **段落自然節奏處** —— 破折號 `──` 前後可加

### 5.2 名詞短語不能被空格拆兩半

| ✗ 錯誤（讀者不知結構）| ○ 正確 |
|---|---|
| 軟趴 貧血 一袋 腐肉 的 烏寬 | 軟趴趴貧血的**腐肉袋**烏寬 |
| 有 牛屎 癖 的 弱雞 | **愛聞牛屎**的變態弱雞 |
| 淌鼻涕 爛鼻頭 小毛球 | 流鼻涕**爛鼻頭**的小毛球 |
| 生殖器 般 的 東西 | 陽痿無膽的廢物 |

### 5.3 判斷原則

- **名詞短語**（形容詞＋名詞、複合名詞）內部：**不加空格**
- **語意單位邊界**（動詞、副詞、句子分隔）：**可加空格**

## 七、每族翻完自查清單（v0.4 §9.6）

- [ ] 遇到英文生造俚語（roof-rabbit / vapor city 等），先問「台灣情境下這個罵詞會怎麼說？」再翻。
- [ ] 玩家 response 讀起來像「玩家艦長會說的話」還是「英文字面拼貼」？
- [ ] 有無醫學/生物學/書面用語混入口語？（陽痿 → 硬不起來）
- [ ] 有無**簡體字**混入？
- [ ] 空格切分是否按語意單位，不是按字數？
- [ ] 該族 voice 是否一致（人稱／標誌性感嘆詞）？
