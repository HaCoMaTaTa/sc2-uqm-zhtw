# Naming Rule 命名規則

> **本檔功能**：翻譯時**遇到新種族、新 NPC、新艦艇、新地點**時的**命名策略**。
> **權威來源**：[Master_Glossary.md](../07_Glossary/Master_Glossary.md)（既有名詞）+ 本檔的**創新策略**。

---

## 一、優先順序（碰到新名詞時的決策樹）

```
遇到新名詞
   │
   ▼
1. 是否已在 07_Glossary/Master_Glossary.md 中？
   │
   ├─ 是 → 使用鎖定譯名（結束）
   │
   └─ 否 → 繼續
       │
       ▼
2. 是否在 07_Glossary/Forbidden_Translations.md 中？
   │
   ├─ 是 → **禁用**，找替代方案
   │
   └─ 否 → 繼續
       │
       ▼
3. 該名詞是否有**明確特徵**可據以命名？
   │
   ├─ 是 → 依「命名優先順序」（見下 §二）產生 3-5 候選
   │
   └─ 否 → 純音譯（見下 §五）
       │
       ▼
4. 產生候選後，**回報使用者選擇**（不自行決定）
   │
   ▼
5. 選定後：
   - 更新 Master_Glossary.md
   - 更新 Fixed_Terms.csv
   - 更新對應的 07_Glossary/*_Names.md
```

## 二、命名優先順序（v0.4 使用者確認）

依以下順序給候選（優先前者）：

### Tier 1：**音譯 ＋ 特徵意象**（最佳）

用**中文字既能音譯 又能傳達種族特徵**。範例：

| 案例 | 說明 |
|---|---|
| **翼哈特族**（Yehat）| 「翼」音近 yee，同時直接呼應鳥人身分 |
| **蘇菩族**（Supox）| 「菩」音近 -pox 尾音，同時呼應菩薩式優雅 |
| **陰嘎族**（Umgah）| 「陰」意為陰險，「嘎」音貼近 gah、呼應 hee-hee-hee 陰笑 |
| **蟾亞族**（Dnyarri）| 「蟾」意為蟾蜍（生理特徵），「亞」音近 nya、同時含「居人下」意象 |
| **毒賈族**（Druuge）| 「毒」呼應惡毒奴役，「賈」呼應商人本質；「毒賈」音近 drooj |
| **撻伐族**（Thraddash）| 「撻」音近 thra、意為鞭打；「伐」音近 dash、意為攻擊 |

### Tier 2：**純特徵意義**（次佳）

無法音義兼顧時，用**純特徵名**。範例：

| 案例 | 說明 |
|---|---|
| **晶智族**（Chenjesu）| 水晶＋智慧 |
| **蛛狂族**（Ilwrath）| 蜘蛛＋宗教狂熱 |
| **平安族**（Safe Ones／Spathi 自稱）| 意譯 |
| **會話寵**（Talking Pet）| 意譯 |

### Tier 3：**順口音譯**（保底）

無明確特徵時，純音譯——**選字要順口、無不良聯想**。範例：

| 案例 | 說明 |
|---|---|
| **阿麗露**（Arilou）| 純音譯 |
| **史怕族**（Spathi）| 純音譯 |
| **姆姆族**（Mmrnmhrm）| 純音譯（原文無母音，擬機械嗡鳴） |
| **佐-佛-皮**（Zoq-Fot-Pik）| 保留連字號結構（三族圖騰） |

## 三、種族命名細則

### 3.1 中文結構

- 3 音節或以下 → 加「族」字（如「蘇菩族」「陰嘎族」）
- 有「商」「者」等本質性尾綴 → **不加「族」字**（如「梅諾商」「會話寵」）
- **例外案例**（不加族字）：
  - **阿麗露**（Arilou）—— shipped v0.3 慣例
  - **梅諾商**（Melnorme）—— v0.4 使用者鎖定
  - **VUX**（保留原文全大寫）
  - **佐-佛-皮**（Zoq-Fot-Pik）—— 連字號結構為圖騰
  - **平安族**（Safe Ones）—— 意譯（此處「族」是意譯詞的一部分，不能省）
  - **會話寵**（Talking Pet）—— 意譯

### 3.2 派系／子族命名

- 主族名 ＋ 派系標記
  - **烏寬克澤札**（Ur-Quan Kzer-Za）＝ 烏寬（主）＋ 克澤札（派）
  - **烏寬柯亞**（Ur-Quan Kohr-Ah）＝ 烏寬（主）＋ 柯亞（派）
  - **翼哈特叛軍**（Yehat Rebels）＝ 翼哈特（主）＋ 叛軍
  - **斯萊探測器**（Slylandro Probe）＝ 斯萊（主）＋ 探測器（機械子分支）

## 四、NPC 命名細則

### 4.1 一般規則

- **音譯優先**、選字要**貼近該族命名文化**（見 §六種族命名文化）
- 首次登場**附英文原名括號**，之後單獨用中文

### 4.2 已鎖定 NPC 一覽

見 [Character_Names.md](../07_Glossary/Character_Names.md)。

### 4.3 遇到新 NPC 時

1. **檢查該族命名文化**（見 §六）——例如：
   - Shofixti NPC → 日文漢字（田中、武士刀、蘿蔔）
   - Melnorme NPC → 顏色（綠光、紫黛、靛冥…）
   - Yehat NPC → 蘇格蘭氏族感（麥卡拉、羅斯之翼…）
2. **產生 2-4 個候選** 給使用者選擇
3. **選定後鎖定** 到 `07_Glossary/Character_Names.md`

## 五、艦艇命名細則

### 5.1 艦級名 vs 具名艦

| 類型 | 中文結構 | 範例 |
|---|---|---|
| **艦級名**（Ship Class）| 不加「號」 | 無畏艦、掠奪者、快艇、母巢艦 |
| **具名艦**（Named Ship）| 末尾加「號」 | 復仇者號（Vindicator）、土柏月亮號（Tobermoon）、刺激者號（Stinger）、於所有情境必勝之艦（綠光的艦名）|

**注意**：有些艦級名本身含「號」或「者」字（如「復仇號」「終結者」），這是命名習慣的一部分——**不代表**它們是具名艦。看**遊戲原文的英文分類**判斷。

### 5.2 中文選字策略

- **重型艦**：用「艦」「者」（沉重感）——如無畏艦、掠奪者
- **輕型艦**：用「艇」（輕巧感）——如快艇、偵察艦
- **武器化艦艇特徵**：用**招牌武器意象**——如火炬艦（Torch）、榴彈砲（歐茲）
- **生物有機艦**：用**生物意象**——如莢艦（Podship）、蜂機艦（Drone）

### 5.3 已鎖定艦艇一覽

見 [Ship_Names.md](../07_Glossary/Ship_Names.md)。

|---|---|---|

| **斯萊族** Slylandro | 詩意短語 | 蘇菩式 |
| **蘇菩族** Supox | 植物 | 需與使用者討論 |
| **翼哈特族** Yehat | 鳥鳴＋-eep 結尾 | 需與使用者討論（原文參考如 "-eep"） |
| **陰嘎族** Umgah | 撇號＋擬聲 | 需與使用者討論 |
| **毒賈族** Druuge | 雙母音 | 需與使用者討論（如 Moola、Duulard） |
| **人類** | 經典科幻 | 巴頓、海斯、齊船長、方斯渥、蘭德 |

## 七、地點命名細則

見 [Place_Names.md](../07_Glossary/Place_Names.md)。核心原則：

1. **恒星系名**：**中華民國天文學會譯名**（船帆座、參宿四、南河三、大角星…）
2. **虛構星系**：音譯（Zeeman-Vela → 日曼-微拉；Groombridge → 葛倫布利吉）
3. **具名行星**：音譯（恩澤伐特 Unzervalt、席拉 Syra）
4. **行星類型**：手冊譯名（氣體巨行星、水行星、輕行星…）

## 八、翻譯 AI 遇到「新未鎖定名詞」時的行為

**絕對不要**：
- ❌ 自行選定譯名並用在正文（會造成不一致）
- ❌ 從使用者《敘事語言學指南》抄新版譯名（已被 v0.4 明確拒絕，見 [Forbidden_Translations.md](../07_Glossary/Forbidden_Translations.md) §1.1）

**應該做**：
- ✅ 產生 3-5 個候選（依 §二 Tier 順序）
- ✅ 說明每個候選的**發音對應**與**意象**
- ✅ **回報使用者**，等待決定
- ✅ 選定後**立刻更新 `07_Glossary/`**
