# Alien Speech Rule 外星語言特殊語法

> **本檔功能**：SC2 各族的**獨特語法特徵**——特殊符號、擬聲詞、宗教用語、對話結構等。這些**格式規則絕不能簡化**——它們是原作 icon。
> **權威來源**：使用者原提詞 §5-6 + 使用者《敘事語言學指南》+ shipped v0.3 各族實例。

## 一、狀聲詞／口頭禪（中譯＋（原文）註記）

### 1.1 政策（v0.4 Phase 14b 2026-08-08 更新，覆蓋 v0.3「保留原文」）

**格式規則**：情緒感嘆詞、招牌狀聲詞、族群口頭禪一律採「**中譯＋全形括號原文**」格式。

**基本形式**：`中文詞！（English!）`

**規則細節**：
- **中文選字**要符合該族人格＋情緒（例：田中的武士 kiai → 「殺呀」而非音譯「凱伊」）
- **中文標點**放在中文詞後（含 `！`）
- **全形括號**包住**完整原文**（含原標點 `!`、`-`、大小寫，一字不動）
- **首次出現原則**：同一 token 內同一狀聲詞重複出現時，**僅首次加註記**，後續保持中文光形（例：`哈！（Ha!） … 再說一次哈！`）
- **不同 token**：每個 token 首次都要加註記（讀者可能跳看任意 token）

```

✓ 唉呀！（Hyai!） 俺真是大蠢材！
✓ 哈！（Ha!） 本人再說一次哈！   ← 同 token 內第二次不重覆註記
```

### 1.4 例外——**不適用此政策**（僅限技術／格式限制 v0.4 Phase 14c 已收緊）

以下情況保持原有規則：

- **Orz `*星號詞*` 格式**：星號結構本身屬格式化 icon **絕對不能動**；但**星號內的文字仍需依政策中譯**（如 `*happy campers*` → `*快樂野餐夥伴*`），見 §六。
- **已有慣例中譯的專有名詞**：Dogar → 多加、Kazon → 卡宗、田中、武士刀、蘿蔔、高麗菜 等既有中譯已完成翻譯，**無需再加英文註記**。
- **Lua template first argument**：`getStarName("船帆座", "start colony")` 中的 first argument 已是遊戲要顯示的名稱，遵循該檔既有慣例。

**重要：以下 v0.4 Phase 14b 之前列為「保留原文」的類別已已納入政策**（Phase 14c 2026-08-08 使用者直接挖定）：

- ✅ **宗教核心用語**：Juffo-Wup、Frungy 等——不再保留原文，並中譯加英文註記
- ✅ **神秘出神／儀式名**：PLAM PRIKKY 等——示範見 §1.2
- ✅ **諺刺品牌／gag 熱線**：1-900-PKUNKRA 等——台灣化中譯示範見 §1.2
- ✅ **族群徒雙招牌歡呼**：Whoopdy Dee / Trolly Bazoo 等——待使用者一例一例挖選

### 1.5 譯者參考

當为 Phase 14d 其他 16 族狀聲詞找中譯時：
- **不要預設保留原文**——新政策：任何非已此翻譯的外星詞彙（包含神聖用語、神秘名、招牌口頭禪、品牌 gag）都應**嘗試提 2-3 個中譯選項**呈給使用者挖選；只有在使用者明確拒絕時才保留原文。
- **選項採取 3 方向**：（1）音譯（呼波迪迪）、（2）意譯（靈啟）、（3）音意兼備（台灣化如 0800-普恩克）
- **不要純音譯**——找情境對應詞（例：Ilwrath Aieee = 邪教徒恐懼 → 或許「阿咦──！」不如「哀嚎」有邪教味）
- **符合人格＋情緒**（例：田中的武士 kiai → 「殺呀」而非音譯「凱伊」）
- **保留原標點**（`!`、`-`、大小寫一字不動）
- **短促原文短，中譯也短**；長嚎原文長（如 HYAIEEE!），中譯拉長（嗚呀啊──！）
- **提 選項時附上你推薦的**（區价 A），使用者選項拒絕時自行採其他選項

### 1.6 排版 icon 中譯的技術規則（v0.7 新增 · 2026-08-16 · **全族通用**）

> **⚠️ 關鍵技術現實**：UQM 遊戲引擎**不支援 Markdown 粗體**——若在 shipped JSON 中寫 `**強調**`，遊戲會**字面顯示兩個星號和「強調」**（`**強調**`）。點陣字型也**無 bold 變體**。

**dossier MD 檔中的表達**（給人類/AI 閱讀）：
- **用 `**粗體**` 標記**表示「這是全大寫 icon 位置」
- 給翻譯師/AI 明確視覺提示

**Shipped JSON 中的等效手法**（**絕不用 `**` 星號**）：

| 手法 | 適用族 | 範例 |
|---|---|---|
| **極簡短句 + 句號密集斷句** | Umgah 心控、Probe、Kohr-Ah | `我方。 為和平。 而來。` |
| **每詞加句號** | Umgah 心控（招牌 icon）| `人族。 干擾。 達到。 無法。 容忍。` |

| **多用機械詞彙** | Probe | 已啟動 / 已鎖定 / 已就緒 / 執行 / 拆解 |
| **感嘆號密集** | Chmmr / Chenjesu / 各族 CAPS 爆發 | `我等即獲自由！！！` |

| **多用剎那斷句 (\\n)** | 所有族 | 用換行強化視覺分隔 |

**寫作 dossier §六 對話範例的推薦格式**（若該族有 ALL CAPS icon）：

## 三、修烈士族 Shofixti 特殊語法

### 3.1 田中（Tanaka）— 熱血武士

- **自稱**：**俺**（所有場合，包括對艦長極正式時仍為俺）
- **感嘆詞**：Kyaiee!（招牌）、Hyai!（輕）、HYAIEEE!（極端）
- **英雄名**：**蘿蔔**（Daikon）
- **母星名**：**高麗菜**（Kyabetsu）
- **句式**：短促、多驚嘆、拉長 KKKK

### 3.2 武士刀（Katana）— 冷靜姊姊

- **自稱**：**本人**（Q4=A 選項，與田中的「俺」形成對比）
- **感嘆詞**：Ha!（招牌）
- **句式**：長句、正式、有時**重複強調**（如「哈！本人再說一次哈！」）

### 3.3 日文漢字保留（Shofixti 專屬例外）

**允許使用**：田中、武士刀（かたな）、蘿蔔（だいこん）、高麗菜（キャベツ→翻）

**理由**：這是**修烈士族的日式風味**——**刻意保留**，不算違反繁體字規則。

## 四、烏寬（Ur-Quan）系列特殊語法

> **⚠️ v0.7 重大修訂（2026-08-15）**：舊定位「吾等 / 爾等」之文言自稱對稱系實證與原文語體不符——原文只是現代英語 `We` / `You`，並非 thou/thee 古語。**中譯以現代官樣命令體為準。**詳見 [../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md](../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md)。

### 4.1 烏寬克澤札 Kzer-Za

- **自稱**：**本平台**（Battle Platform 的翻譯，保留為機械化 icon）、**我方 / 我們**（v0.7 代替舊「吾等」）
- **對玩家稱呼**：**你 / 你們**（v0.7 取代「爾等」）、**卑微者**、**待奴役者**、**此類生物**
- **句式**：**現代極正式命令體**、無感情色彩、極長句子（`Your independence is too dangerous for us to tolerate` → 「你方獨立對我方而言已屬危險，不可容忍。」）
- **語氣**：**絕對權威、無爭辯餘地**
- **教條詞**：現在與永恆之道、Fallow Slave、Battle Thrall

### 4.2 烏寬柯亞 Kohr-Ah

- **自稱**：**我方 / 我們**（v0.7 代替舊「吾等」）、**淨化者**、**永恆執行者**
- **對玩家稱呼**：**你 / 你們**、**待淨化者**、**污穢生命**、**應被抹除的存在**
- **句式**：**極簡冷酷宣告式現代英語**（`We do not kill. We cleanse.` → 「我方不殺戮。我方只淨化。」；`You are filth.` → 「你方是污穢。」）
- **語氣**：**冰冷但帶宗教熱情**（與克澤札的純冷酷不同）
- **教條詞**：永恆教條、Cleansing（淨化）、Filth（污穢）、Purification

### 4.3 烏寬合體時（背景故事）

若翻譯到烏寬**教義戰爭**背景時：
- **克澤札稱柯亞為**：叛徒、狂熱者、失去理智者
- **柯亞稱克澤札為**：軟弱者、拖延真理者、汙染源

## 五、蛛狂族 Ilwrath 特殊語法

> **⚠️ v0.7 實證補充（2026-08-15）**：新發現 Ilwrath 原文一個重要 icon——**每個實詞首字大寫**（`We Have Spent Many Years Gleefully Preying On The Pkunk`）。這是 Ilwrath 對白的招牌排版 icon，中譯雖無法直接複製英文首字大寫，但**可用拘謹極儀式化的句式來對應**（例如：句子強行齊整化、每小句以「、」分隔、避免當代口語進行式、多用「執行」「奉行」「聞達」等儀式化動詞）。邪神 Dogar/Kazon **廣播則使用極端 ALL CAPS**（`WORSHIP US!` → 「崇拜我等！」，建議全部包**粗體**強調）。

### 5.1 禱詞口吻

**每句對白幾乎都是對邪神的禱告**，英文以首字大寫招牌格式呈現：

```
聽哉，偉大的多加！
聞我等哉，血腥的卡宗！
以爾等之名，我等執行殘忍！
```

**翻譯手法**：
- **「聽哉」「聞我等」「我等」**（禱詞慣用）
- **「偉大的多加」「血腥的卡宗」**（多加=Dogar；卡宗=Kazon）
- **「AIEE！」保留原文**

### 5.2 自我懲罰儀式

**遲到／失誤時**，Ilwrath 會**自扯附肢**懺悔：

```
祈禱眾神原諒我等尚未開始屠戮撒達許族。
速速，我必自胸節扯下三根附肢以示懇求。
AIEE！
完成了！多加與卡宗見我體液必展笑顏。
```

**翻譯手法**：**保留原文的殘忍儀式感**——不美化。

### 5.3 對玩家的鄙稱

- **「肉肉人類」**（fleshy humans）
- **「靈長類胡話」**（primate babble）
- **「可憎的凡人」**

| `*play*` | `*玩耍*` | 維度侵蝕／捕食（表面） |
| `*parties*` | `*派對*` | 集會（實質為捕食） |
| `*germinate*` | `*發芽*` | 實體增殖 |
| `*fried!*` | `*被油炸了！*` | 招牌驚呼 |
| `*Space Marines*` | `*太空探險隊*` | 歐茲艦艇的登艦部隊 |
| `*Go-Gos*` | `*Go-Gos*` | 保留原文（音樂梗）|
| `*Alliance Party*` | `*聯盟派對*` | 加入聯盟＝來派對 |

### 6.3 星號規則細節

- **前後空格**：`Orz *開心* 因為`（星號兩側不加空格）
- **標點與星號**：`*fried!*` → `*被油炸了！*`（**驚嘆號進入星號**）
- **多字保留**：`*happy campers*` → `*快樂野餐夥伴*`（**多字仍保留一對星號**，不拆多對）

### 6.4 觸發雷區

**追問 Androsynth 時**歐茲**瞬間敵化**：
- 星號詞語從**歡樂**（`*快樂*` `*滑順*`）變**沉重**（`*沉重的空間*` `*heavy space*`）
- 語氣冰冷
- 保留星號、但**選字反映敵意**

### 6.5 自稱不用「我」

**嚴禁**使用「我」或「我們」——用：
- **Orz**（單數）
- **Orz們**（複數）
- **Orz 覺得**（動詞前）
- **從\*底下\*來的 Orz**（詩意時）

### 6.6 對玩家的稱呼

- **\*露營者\***（`*campers*`）
- **\*新前輩\***（`*new boys*`）
- **\*快樂野餐夥伴\***（`*happy campers*`）
- **\*傻牛牛\***（`*silly cows*`）

### 8.3 兩層切換原則

### 9.1 Juffo-Wup 貫穿全部對白

```
你是新的存在……Juffo-Wup 溫柔地觀察你……
```

## 十、憂特族 Utwig 特殊語法（面具禮儀＋兩階段）

> **⚠️ v0.7 重大修訂（2026-08-15）**：語體定位從「莎士比亞式悲劇詠嘆調」改為 **「現代學者式憂鬱華麗長句 + 官僚報告體 + 冷式反諷」**。詳見 `02_Races/Utwig.md` §四 v0.7 修訂說明。**避免文言古語**（吾/爾/之/乃/矣/哉）——原文根本無 thou/thee/thy 等古語，只是現代教授式冗長句 + 官樣文。

具體對白中出現的 15 個面具 canonical 對照見 `02_Races/Utwig.md` §八 或 `translations/utwig.zh-TW.json` `_notes`。

- **自稱**：**我方 / 我們憂特**（預設，官方口吻）；**悲慘的憂特族 / 失落的憂特**（戲劇性場合少量點綴）

### 10.4 兩期切換

**翻譯時**：兩期**語氣完全轉變**——**不能有殘留憂鬱感**在狂喜期，反之亦然。

## 十二、翼哈特族 Yehat 特殊語法（蘇格蘭中世紀騎士 + 鳥類擬聲）

> **⚠️ v0.7 重大修訂（2026-08-15）**：舊定位「文言化」實證不符。sa-matra 對白庫實測 Yehat 原文為 **蘇格蘭勇士腔**（`ye/fer/canna/'Tis/yer/methinks/hark`）+ **鳥類擬聲**（`BRAAK!/AWK!/HISS!/HOOT!`），**不是** thou/thee/thy 古英文。詳見 [../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md](../00_Project_Control/Dossier_Voice_Audit_2026-08-15.md)。
>
> **v0.7 新定位**：中譯取 **台灣武俠小說風 + 中世紀騎士語彙 + 模擬 Robert Burns / Braveheart 式英雄氣盛**，**不可濼用吾／汝／之／乃等文言助詞**。

### 12.1 自稱、對稱、自命名號

- **自稱**：**本騎士**（單人，保留）、**我騎士**、**本族戰士**、**我方 / 我們葉哈**（v0.7 代替舊「吾 / 吾等」）、**本氏族**、**本艦**（保留為騎士稱呼其座驕之物，不屬文言）
- **對玩家**：**你 / 你們**（預設，v0.7 代替舊「汝 / 爾」）、**兒**、**兒台**（台灣武俠風）、**同盟騎士**、**人類戰士**、**地球艦長**

### 12.2 儀式性讚頌（v0.7 均重寫為武俠體，不入文言）

**每句對白**幾乎都有**莊嚴讚頌**：

```
以氏族之名發誓！
以先祖双翼之名起誓！
榮光归於我族！
（呼──啦──！）
```

### 12.3 招牌鳥類擬聲（v0.7 新增重點）

**鳥鳤擬聲是 Yehat 招牌 icon**，需保留（中譯將口語化後附原文）：

| 原文 | v0.7 中譯 | 使用時機 |
|---|---|---|
| **BRAAK!** | 呐──呼！（BRAAK!） | 衝錫呼嗊、戰鬥呼喊 |
| **AWK!** | 嗄！（AWK!） | 情緒驚噸、小驚呼 |
| **HISS!** | 嘶──！（HISS!） | 不屑、隃遮 |
| **HOOT!** | 呐──！（HOOT!） | 雄心玩肯 |
| **Lykeee-lieee!** | 保留原文 | 騎士呼唤 |
| **Ho!** | 你好！（Ho!） | 開場招呼 |

**句首或句尾夹雜擬聲**（如 Utwig 面具語彙、Orz 星號詞）——**這是 Yehat 的 icon**，不可省略。
