## §附錄 B:翻譯格式規則索引(來自提詞 md §4)

**星圖交叉參照鐵律**:對話 token 首次提到任何星系/星座/恆星/行星/星群 → 必附英文原文 `中譯（English）`。**理由**:遊戲內 Starmap 純英文,玩家找中譯定位不到。

- ✅ `Beta Orionis` → 獵戶座β（Beta Orionis）

- ❌ `Buenos Aires` / `Mexico` 不附英文(地球地名玩家看得懂)

## §附錄 C:實務決策原則的來源

以下決策原則,凡有標註者依此優先序:

1. **音節奇特無意義的種族名** → 音譯,控制 2-3 字(如 Yuli 尤利族)
2. **有明確含意/性格暗示** → 意譯/在地化(如 Spathi 史怕族的「怕」)
3. **90 年代科幻慣例已定** → 從眾(如 Credits = 星幣)
4. **華文玩家社群已有普遍中譯** → 從眾(如 Betelgeuse = 參宿四)
5. **原文本身就是招牌音效/擬聲/字型** → 保留原文(如 SNORT / Kyaiee / *silly cows*)
6. **官方定義有明確功能** → 意譯功能(如 MetaChron 終時儀 = 預測自身毀滅)
7. **同族命名法一致性** > 個別詞的最佳翻譯(如 Yehat Rebels 個體全音譯保留鳥人異族感)
