# Star Control II 繁體中文專有名詞對照表（工作稿 v0.2）

> **v0.2 變更摘要**（2026-08-04）：全面重新設計種族名稱，改採「≤3 字 + 族」原則。設計依據見 [SC2-種族名稱重新設計.md](SC2-種族名稱重新設計.md)。已修正 Thraddash 舊譯錯誤。
>
> **編纂原則**（來自使用者授權：音意混合、視詞而定；記憶度優先，必要時在地化）
> - 音節奇特無意義的種族名 → **音譯**，控制在 2–3 字。
> - 有明確含意或性格暗示 → **意譯/在地化**，能傳達性格者優先（如 Spathi→史怕族）。
> - 遊戲玩家社群已有普遍中譯 → **從眾**，避免造出新詞造成溝通斷層。
> - 網梗/幽默/雙關 → 註記，翻譯時保留笑點。
> - 首次出現：`中譯（English）`；重複出現：只用中譯。
>
> **符號說明**
> - 🎯 音譯　🌱 意譯　🎨 音意混合　🎭 在地化（性格暗示或雙關）　⚑ 需保留原味的網梗　★ 大改動需注意

## 七、Orz 專用星號術語（保留原味）

Orz 台詞的 `*...*` 星號要保留為視覺特徵。以下列出重要語塊：

| 原文 | 中譯 | 語意 |
|---|---|---|
| `*happy campers*` | `*快樂野餐夥伴*` | 開心的一群 |
| `*juice*` | `*果汁*` | 生命 / 存在 |
| `*many bubbles*` | `*許多泡泡*` | 情緒起伏 |
| `*Space*` | `*空間*` | Orz 所屬維度 |
| `*Below*` | `*底下*` | Orz 的來處 |
| `*heavy space*` | `*沉重的空間*` | 敵對 / 危險狀態 |
| `*smooth*` | `*滑順*` | 順利 |
| `*camper party*` | `*野餐派對*` | 集會 |
| `*silly cows*` | `*傻牛牛*` | 對其他種族的稱呼 |
| `*pretty party*` | `*漂亮派對*` | 好事 |
| `*dancing*` | `*跳舞*` | 戰鬥 |

> Orz 台詞翻譯建議**保留星號、保留怪異詞序**，這是原作標誌。
