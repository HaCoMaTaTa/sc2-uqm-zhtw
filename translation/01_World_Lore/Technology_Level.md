# 科技水平 Technology Level

> 各族科技差異巨大，翻譯時要意識到「這個族的角色講話時，會用什麼樣的科技詞彙」。

## 一、宇宙尺度的物理／空間

| 概念 | 中譯 | 說明 |
|---|---|---|
| TrueSpace | 真實空間 | 我們熟悉的四維時空 |
| HyperSpace | 超空間 | 平行維度，用於**縮短星際距離**；星系顯示為亮點、外星船為暗點；有紅位移現象 |
| QuasiSpace | 準空間 | 更神祕的維度，阿麗露母星藏於其中；每月只有 4 天可進入；玩家透過特殊裝置進入 |
| HyperWave | 超波通訊 | 跨星際通訊技術，速度超光；晶智族最早使用；Druuge 也擅長 |

**翻譯時注意**：「HyperSpace = 超空間」不要被 1990 年代舊譯「外太空」帶偏（那個譯法會跟現代中文的「宇宙空間」混淆）。

## 四、跨族科技等級對照（大略）

```
極高 ────────────────────────────────────── 極低
先驅者（Precursor，已滅絕）
   └─ Chenjesu / Chmmr（矽晶／融合體）
        └─ Ur-Quan（無畏艦、Sa-Matra 使用者）
             └─ Mmrnmhrm（機械種族）
                  └─ Arilou（維度技術）
                       └─ Yehat / Chenjesu 加持前的地球人（1970 年代科技）
                            └─ Spathi / Shofixti / VUX
                                 └─ Slylandro（借 Melnorme 探測器才能出星球）
                                      └─ Thraddash（低階艦艇）
                                           └─ Zoq-Fot-Pik（快被打爆的等級）
                                                └─ Burvixese / Gg 等已滅絕族群
```

**特殊定位**：

- **Melnorme（梅諾商）**——科技高但不用於戰爭；賣資訊給人賦錢
- **Druuge（毒賈族）**——中等科技 + 極端商業手段；賣騙人商品
- **Orz**——來自別的維度，「科技」的概念可能不適用他們

## 六、翻譯時的科技詞選字原則

- **保留原詞的科幻氛圍**：不要把「Fusion Blaster」翻成「聚變爆能砲」（大陸用語）而是「融合爆能砲」
- **雙關保留**：Guardian（守衛艦）、Avenger（復仇號）、Terminator（終結者）——保留意譯，因為原文就有戰術暗示
- **首字母保留**：MASER、VUX、RU 等縮寫可保留半形英文
- **禁用**：「服務器」「視頻」「文件」「軟件」「智能」等中國大陸用語 → 用「伺服器」「影片」「檔案」「軟體」「智慧」
