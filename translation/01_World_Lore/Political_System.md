## 二、自由星系聯盟（Alliance of Free Stars）

### 舊聯盟（SC1，2116–2135）

| 成員 | 現況 |
|---|---|
| 人類（地球） | 禁足奴族（防護罩下） |
| 晶智族（Chenjesu） | 進防護罩融合中（→ 查姆族） |
| 姆姆（Mmrnmhrm） | 進防護罩融合中（→ 查姆族） |
| 葉哈（Yehat） | 大部分為烏寬戰奴；葉哈叛軍（Yehat Rebels）反抗中 |
| 修飛（Shofixti） | 幾乎滅族（自爆恆星換取聯盟撤退）；剩少數散兵 |
| 阿麗露（Arilou） | 神秘退隱於準空間 |
| 塞蓮（Syreen） | 舊家園被摧毀；散居宇宙 |

### 新聯盟（SC2，玩家組建中）

玩家的任務是**從 Vindicator 一艘旗艦重建聯盟**：招募重返的舊盟友、拉攏新盟友、對抗烏寬。

## 三、烏寬戰奴階層（Ur-Quan Hierarchy of Battle Thralls）

**通稱**：階層 / 戰奴階層 / 階層集團

### 內部結構

```
        Ur-Quan（烏寬族，兩派內戰）
       ┌───────┴───────┐
     克澤札          柯亞
   （綠系奴役派）  （黑系滅絕派）
       │
       ▼
   Battle Thrall（戰奴）─ 為烏寬作戰的被征服族
       ├─ 麥孔（Mycon）
       ├─ 史怕（Spathi）
       ├─ 姆嘎（Umgah）
       ├─ VUX
       ├─ 安卓辛（Androsynth，SC2 開場神秘消失）
       └─ 蛛狂（Ilwrath）

   Fallow Slave（禁足奴族）─ 被防護罩封印的被征服族
       ├─ 地球
       ├─ 塞蓮（Syreen，舊家園）
       ├─ 晶智族 / 姆姆（自願，用於融合）
       └─ 葉哈（大部分保皇派）
```

### 兩派差異對翻譯的影響

| 條目 | 克澤札（綠系） | 柯亞（黑系） |
|---|---|---|
| 教條 | Path of Now and Forever | Eternal Doctrine |
| 中譯 | 現在與永恆之道 | 永恆教條 |
| 對其他族的處置 | 奴役 or 封印 | **徹底滅絕** |
| 語氣 | 威嚴、階級分明、將奴役視為必然 | 冷酷、絕對、宗教式淨化 |
| 招牌句 | （對戰奴發號施令風格） | 「YOU are the filth. We cleanse.」 |

## 四、中立／獨立種族

**特徵**：想置身於烏寬 vs 聯盟戰爭之外，各有理由。

| 種族 | 立場 |
|---|---|
| 憂特族（Utwig） | 失去 Ultron 後全族陷入哲學崩潰，無心他顧 |
| 蘇菩族（Supox） | 憂特族的文化盟友；跟隨憂特態度 |
| 普恩族（Pkunk） | 翼哈特族靈修分支；正與蛛狂族交戰 |
| 斯萊族（Slylandro） | 氣態行星生物，無法離開母星；探測器意外攻擊他族 |
| 毒賈族（Druuge） | 極端資本主義者；賣人、賣情報、賣壞掉的神器 |
| 梅諾商（Melnorme） | 商人身分，賣資訊給玩家換錢或彩虹世界座標 |
| 歐茲族（Orz） | 從別的維度湧入，佔據 Androsynth 原本的空間 |
| 佐-佛-皮 | 三族聯盟，被夾在烏寬內戰中間，隨時滅族 |
| 撻伐族（Thraddash） | 被烏寬留在 Draconis「顧後方」；驕傲又羞恥 |

## 五、翻譯時的政治／稱謂原則

### 官職與稱謂

| 原文 | 譯法 | 說明 |
|---|---|---|
| Captain | 艦長 | 玩家與其他艦艇指揮官通用 |
| Commander | 指揮官 / 艦長 | 視上下文；Commander Hayes = 海斯艦長（因是星際基地指揮官） |
| Admiral | 上將 / 提督 | 高階；ZEX 是 Admiral |
| Emperor / Empress | 皇帝 / 女皇 | 翼哈特族有女皇 |
| Queen | 女王 / 女皇 | 翼哈特族用 |
| Master | 主人 / 主宰 | 蟾亞族用「Master」呼玩家（心靈控制暗示） |
| Slave | 奴隸 / 戰奴 / 禁足奴族 | 依上下文；Battle Thrall 特別譯「戰奴」 |
| Trade Master | 貿易官 | Melnorme 高階商人職稱 |

### 對敵／對友的稱謂

- **烏寬對其他種族**：貶稱居多——「Battle Thrall（戰奴）」「filth（污穢）」「insect（蟲豸）」「lesser life-form（低等生物）」
- **柯亞對其他種族**：更冷酷——「dust（塵埃）」「that which we cleanse（我們所淨化者）」
- **地球艦長／玩家**：友好種族用「Captain」；敵對種族用貶稱
- **同陣營間**：「盟友」「同志」「兄弟」——選字看該族文化（翼哈特族武士感、晶智族學者感）
