## 為什麼要 pin SHA

MegaMod 主幹持續更新（AGP / SDK / bug fix），若我們套 patch 時對到不同 upstream，會 conflict 甚至 build 出無法運作的 exe/apk。鎖 SHA 保證：

1. **同步性**：本 repo 內任何工作站都能重現一模一樣的 build
2. **可回溯**：發現問題可 checkout 這個 SHA 對照
3. **升 upstream 有紀律**：想跟上 upstream 時，更新此檔並重跑 3-gate 驗證
