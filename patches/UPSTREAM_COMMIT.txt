## patches/*.patch 的角色

本資料夾內的 31 個 `.patch` 檔**不是**必須套用的檔案，而是：

1. **歷史紀錄**：每個 patch 記錄「這個變動針對什麼問題、為什麼要改」
2. **教學材料**：新 maintainer 可以照 patches/ 順序理解專案演進
3. **rebase 素材**：未來若上游 major update 打散了 commit，可用 patches 快速重新對齊

## 如何升 upstream（跟上 JHGuitarFreak 官方最新變動）

1. 在你的 fork 內：
   ```powershell
   cd Q:\path\to\UQM-MegaMod
   git remote add official https://github.com/JHGuitarFreak/UQM-MegaMod.git
   git fetch official
   git merge official/master   # 或 rebase，依情況選
   ```
2. 解決衝突（本專案 patch 大多動 `src/uqm/planets/report.c`、`src/libs/uio/`、
   `build/android/`）
3. 測試 build（PC + Android）
4. 更新 UPSTREAM_COMMIT.txt 內 SHA
5. `git push` 到你的 fork
