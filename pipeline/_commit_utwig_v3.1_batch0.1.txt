## Discovery

After Batch 0 (paren sweep), extended scan revealed massive additional drift:

| Type | Before | After | 全形 baseline |
|------|-------:|------:|-------------:|
| `,` CJK-CJK | **260** | 0 | melnorme/syreen: 0 |
| `:` CJK-CJK | **18** | 0 | others: 0 |
| `;` CJK-CJK | **6** | 0 | others: 0 |

Utwig v0.1 shipped translator used Western-style ASCII punctuation heavily
inside CJK dialog (comma 92.7% half-width, colons/semicolons 100% half-width).
This is unique among race files — syreen/mycon/melnorme/pkunk (post-audit)
use 100% full-width CJK punctuation.

## Normalization Applied

Dialog values only (skipped `_notes` annotations, which are internal translator
comments and legitimately use Western-style punctuation in annotations):
- 260 × `,` → `，` (between CJK chars)
- 18 × `:` → `：` (between CJK chars)
- 6 × `;` → `；` (between CJK chars)
= 284 total punctuation edits

Iterative regex applied to catch chained instances (e.g. 「A,B,C」 where
after `A,B → A，B`, the next pass catches `B，C → B，C` — no, wait that's
already CJK-CJK. The iterative loop ensures no missed cases.).

Preserved:
- Half-width `,` in English content (inside 「（Bah!）」etc.)
- Half-width `,` around numbers (`1,000`)
- Half-width `,` inside template `<%...%>` blocks
- `_notes` annotation punctuation (1 item restored)
